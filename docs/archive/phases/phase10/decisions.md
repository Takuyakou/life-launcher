# Phase 10(UI/UX の作り直し)の決定

リードが書く。利用者の決定は日付つき。**指示書と食い違ったら、ここが上**(リードが指示書を直す)。
見本:`handoff\mocks\index.html`(キャンバスの 15 画面を単体の HTML にした物)。見本と、ここの決定が食い違ったら、ここが上。

## 全体の方針(2026-11-12〜15)

- アプリの核は「今やる一手を始める」。ほかの物(ランチャー・辞書・手順書・記録)は、それを助けるわき役に下げる。
- やらないこと(前から):カレンダー・ヒートマップ・連続日数・点数・自動の繰り越し。今日の3件は 3 件まで。
- 色の役割:**黄色 = 決める**、**緑 = 保存・決定・始める**、**赤 = キャンセル・閉じる**、灰色 = 止めた・外した。
- ダイアログの下のボタンは、**左が保存・決定(緑)、右がキャンセル(赤)**(今のアプリと同じ。利用者が指定した配色)。
- 暗い画面の今の色(`src/styles.css` の `:root`)を土台にする。新しい色を足すときは、指示書に値を書く。
- 控えめな変更が好み。説明文やボタンを大胆に削る引き算はしない。
