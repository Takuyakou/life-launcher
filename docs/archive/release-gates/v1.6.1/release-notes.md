# Life Launcher v1.6.1

手順書の本の画面を、もっと読みやすくしました。今までのデータはそのまま使えます。

## 新しくできる事

- 読みたいページへ、すぐ移れます。上のページ表示を押すか Ctrl+G を押して、ページの数を打ちます。
- 下の線を押す・引くと、その場所のページへ移れます。
- 拡大・縮小ができます(全体から 400% まで)。右上の − と ＋、Ctrl を押しながらホイール、キーボードの + − 0 で操作します。
- 拡大している時は、ホイールとマウスで引く操作で、ページの中を見て回れます。拡大の倍率は、教材ごとに覚えます。

## 直した事

- ページをめくる時に、一瞬暗くなっていたのを直しました。めくると、すぐに替わります。
- 大きな画像の ZIP で、ページが読み込み中のまま出ない事があったのを直しました。
- 手順書の窓を閉じた後も、ZIP のファイルを開いたままにしていたのを直しました。
- 手順書のフォルダの名前を変えたり動かしたりすると、中の ZIP の続きのページが初めに戻っていたのを直しました。
- 「元に戻す」が付いた知らせが出ている時間を、8 秒から 5 秒に短くしました。

## ダウンロード

- `Life-Launcher-v1.6.1-windows-x64-setup.exe`:インストールして使う版(ふつうはこちら)
- `Life-Launcher-v1.6.1-windows-x64.exe`:インストールせずに使う単体版
- `Life-Launcher-v1.6.1-windows-x64-portable.zip`:単体版を ZIP にした物
- `SHA256SUMS.txt`:ダウンロードしたファイルが壊れていないかを確かめるための値

## 更新する前に

- 自動の更新はありません。Life Launcher を完全に終了してから、新しい版をインストールしてください。
- 念のため、エクスプローラーのアドレス欄に `%APPDATA%\life-launcher` と入れて開き、そのフォルダを丸ごと別の場所にコピーしておいてください。
