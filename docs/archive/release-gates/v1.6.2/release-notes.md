# Life Launcher v1.6.2

手順書の窓を、もっと広く使えるようにしました。今までのデータはそのまま使えます。

## 新しくできる事

- 手順書の窓の左の一覧を、小さなボタンで閉じたり開いたりできます。一覧の見出しの右の「<」で閉じ、閉じた時は左の細い帯の「>」で開きます。閉じた状態は、次に開いた時も覚えています。
- 一覧と本文の間の仕切りをダブルクリックしても、一覧を閉じられます。一覧を、前より狭くもできます。

## 直した事

- 本の画面で、ページの左の端にマウスを乗せると、ページが少し暗くなっていたのを直しました。右の端の矢印が見えなかったのも直しました。
- 本の画面の「全体」で、小さい画像も画面いっぱいに出すようにしました。拡大した時に、大きさが急に変わる事が無くなりました。
- ページの周りの余白を詰めて、ページを大きく出すようにしました。

## ダウンロード

- `Life-Launcher-v1.6.2-windows-x64-setup.exe`:インストールして使う版(ふつうはこちら)
- `Life-Launcher-v1.6.2-windows-x64.exe`:インストールせずに使う単体版
- `Life-Launcher-v1.6.2-windows-x64-portable.zip`:単体版を ZIP にした物
- `SHA256SUMS.txt`:ダウンロードしたファイルが壊れていないかを確かめるための値

## 更新する前に

- 自動の更新はありません。Life Launcher を完全に終了してから、新しい版をインストールしてください。
- 念のため、エクスプローラーのアドレス欄に `%APPDATA%\life-launcher` と入れて開き、そのフォルダを丸ごと別の場所にコピーしておいてください。
