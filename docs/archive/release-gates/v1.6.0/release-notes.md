# Life Launcher v1.6.0

手順書で、画像の入った ZIP を本のように読めるようになりました。今までのデータはそのまま使えます。

## 新しくできる事

- 手順書のフォルダに、画像の入った ZIP を置くと、本のように開けます。
- 見開きと1ページ、右から左と左から右を切り替えられます。初めは、見開き・右から左で、表紙だけ1ページで出します。
- めくるのは、キーボードの ← →・PageUp・PageDown・Space・Home・End、ページの左右を押す、マウスのホイールのどれでもできます。
- 教材ごとに、最後に見たページと、見開きや向きの切り替えを覚えます。次に開くとそこから始まります。
- 今やる一手の手順書が ZIP の時、札に「p.34」のように、続きのページが出ます。押すと、そのページから開きます。
- 左の一覧では、ZIP は桃色の写真の印で出ます。フォルダと見分けが付きます。

## 安全のために

- 開くのは、ZIP の中の画像(JPEG・PNG・WebP・GIF)だけです。中身が画像でない物や、それ以外の種類のファイルは開きません。
- ZIP をパソコンに展開しません。中のファイルが勝手に置かれる事はありません。
- 1枚が64MBより大きい画像、4GBより大きい ZIP は開きません。RAR には対応していません。

## 直した事

- 記録で「すべての記録」に切り替える時に、下に横のスクロールバーが一瞬出ていたのを直しました。
- 手順書の一覧で、フォルダの名前を 1 回押すだけで開け閉めできるようにしました。開け閉めの動きも、メインのサイドバーと同じ滑らかな物にしました。

## ダウンロード

- `Life-Launcher-v1.6.0-windows-x64-setup.exe`:インストールして使う版(ふつうはこちら)
- `Life-Launcher-v1.6.0-windows-x64.exe`:インストールせずに使う単体版
- `Life-Launcher-v1.6.0-windows-x64-portable.zip`:単体版を ZIP にした物
- `SHA256SUMS.txt`:ダウンロードしたファイルが壊れていないかを確かめるための値

## 更新する前に

- 自動の更新はありません。Life Launcher を完全に終了してから、新しい版をインストールしてください。
- 念のため、エクスプローラーのアドレス欄に `%APPDATA%\life-launcher` と入れて開き、そのフォルダを丸ごと別の場所にコピーしておいてください。
