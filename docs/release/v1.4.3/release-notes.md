# Life Launcher v1.4.3

手順書ビューアーでMHTMLを読めるようにし、設定とタスクトレイにバージョンを表示しました。プロジェクト・次の一手・やりたいことをJSONでまとめて取り込めるようになり、プロジェクトの色を12色に増やし、「やりたいこと」の節を見やすくしました。データ形式の変更はありません。

## 手順書ビューアーでMHTMLを開く

- `.mhtml` / `.mht` を、HTMLと同じ「見るだけ」で開けるようにしました。Chrome・Edgeの「ウェブページ、1つのファイル」で保存したものを想定しています。
- ファイルの中の画像（PNG・JPEG・GIF・WebP）とCSSを埋め込んで表示します。上限は20 MBです。
- 表示できないものがあります。SVGなどの画像、埋め込みのフォント、スクリプトで動く部分、フォーム、入れ子のフレーム、外部の画像・CSSは表示されません。壊れたファイルや大きすぎるファイルは、理由を出して開きません。
- HTMLの手順書と同じく、アプリ内では編集できません。

## バージョンの表示

- 設定の「メンテナンス」の一番下に、アプリのバージョンを出すようにしました。
- タスクトレイのアイコンの説明にも、バージョンを出すようにしました。

## JSONでまとめて取り込む

- プロジェクト・次の一手・やりたいことを、JSONでまとめて足せるようにしました。ファイルをメイン画面に落とすか、取り込みの画面に貼り付けます。
- ChatGPT・Claude用のプロンプトを「使い方」と取り込みの画面に用意しました。「はじめて用」と「2回目以降用」の2つがあり、2回目以降用は今のプロジェクト名・目標・次の一手・やりたいことを付けてコピーできます。
- 今あるプロジェクトは上書きせず、足りない色や目標だけを補います。すでに次の一手があるプロジェクトの次の一手は、やりたいことに入ります。
- 取り込んだあとの「元に戻す」で、取り込む前に戻せます。

## プロジェクトの色

- プロジェクトの色を4色（ライム・マゼンタ・サンド・コーラル）増やし、12色から選べるようにしました。
- 色を指定していないプロジェクトは、今までどおり自動の色で表示します。

## 「やりたいこと」の節

- プロジェクトごとのまとまりが分かるように、見出しを低い行にし、項目を右へ字下げしてプロジェクトの色の線を付けました。
- 同じグループの項目は薄い線で区切り、グループの間は広めの間隔で分けました。
- 「未分類」は、いつも一番最後に表示します。並べ替えの対象にはなりません。

## 窓の閉じるボタンとCtrl+W

- 閉じるボタンを押しやすくしました。ボタンの幅を広げ、見た目を変えずに窓の右端まで押せる範囲を広げています。最大化しているときは、画面の右上の角でも閉じられます。
- Ctrl+Wでも、閉じるボタンと同じように閉じられます。メイン画面はタスクトレイに隠れ、手順書ビューアーは閉じます（保存していない編集があるときは確認が出ます）。
- 設定で変えられるショートカットにCtrl+Wを選ぶことはできません。すでに設定にCtrl+Wがある場合は、その設定を優先します。

## 直したこと

- 手順書ビューアーを初めて開いたときに、十字キーが効かないことがあるのを直しました。
- 窓の内側の余白をつかむと窓が動くのを直しました。
- 記録画面を開いたままタイマーを終えても、「今日」の分数が増えないのを直しました。
- ミニタイマーのボタンを素早く2回押すと、メイン画面に戻るのを直しました。
- 設定画面の↑で、選んでいるタブに戻らないのを直しました。
- 窓を元に戻した直後に、ボタンの乗せた色が残るのを直しました。
- 止める・外す・削除する操作のトーストを、緑から灰色にしました。

## 開発向け

- テスト用の起動（`LIFE_LAUNCHER_TEST_PROFILE`、`scripts/start-test-profile.ps1`）を追加しました。
- 開発用のESLintを更新し、使っていない古いコードを削除し、READMEを整理しました。
- AIツールの設定ファイルと秘密情報の公開防止ガードを追加しました。

## v1.4.2から更新する方へ

- config schemaは`3`のままで、設定データの形式はv1.4.2から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.4.3-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.4.3-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.4.3-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

## 既知の制限

- UIは日本語中心で、英語対応は主に上部ツールバーなどの一部です。
- ウィンドウ: Windows 11で、最大化ボタンにマウスを乗せたときに出る配置の選択（スナップレイアウト）は出ません。アプリで作ったボタンのためです。画面の端へドラッグしたときのスナップと Win+Z はWindowsの機能ですが、この版では動作を確かめていないため、使える前提にしていません。
- URLはWindowsの既定ブラウザで開きます。
- ブックマーク名の取得は、ローカルのブラウザープロファイルを読める場合に限ります。
- HTML手順書は、静的なHTML/CSSと登録したフォルダー内の相対assetだけを表示します。JavaScriptに依存する画面、フォーム、入れ子のフレーム、外部のassetは、安全のため動作しません。HTMLの手順書は表示だけで、アプリ内では編集できません。
- MHTMLは、PNG・JPEG・GIF・WebPの画像とCSSだけを埋め込みます。SVGなどの画像、埋め込みフォント、スクリプトで動く部分、フォーム、入れ子のフレーム、外部の画像・CSSは表示されません。20 MBを超えるファイルは開けません。
- プロジェクトの新しい4色（ライム・マゼンタ・サンド・コーラル）は、v1.4.2以前の版では自動の色で表示され、その版で保存すると色の指定が消えます。前の版へ戻す前に、`%APPDATA%\life-launcher`をバックアップしてください。
- 画面の確認は、開発環境のWindows(Chromium)での画像比較と、ビルド済みアプリでの確認を組み合わせています。表示倍率やフォントが異なる環境では、折り返しの位置などが少し違う場合があります。
- タイマーの開始・一時停止は、スクリーンリーダーでは自動で読み上げません（通知をやめたため。画面のボタンと時計の表示で示します）。
