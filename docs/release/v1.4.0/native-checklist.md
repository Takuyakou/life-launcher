## 1. 表示サイズ 大・特大 の今日の3件の見出し

手順:

1. `release-candidate/native-check/launch-v140-isolated.bat` をダブルクリックして起動する(隔離したテスト用プロファイルで起動する。実際のデータには触れない)。
2. 設定 > 表示 で、メイン表示サイズを「大」にする。続けて「特大」にする。
3. メイン画面の「今日の3件」の見出しと、その下の「次の一手」の見出しを見る。

期待する結果(「大」「特大」の両方):

- 「今日の3件」の説明文(「今日やると決めたもの。タイマーから開始します。」)が、「n / n 完了」のすぐ後ろにある(右端に寄っていない)。
- 「次の一手」の見出し(件数、説明文)と、並びがそろっている。
- 「標準」に戻しても、見え方は今までどおり。

## 2. 今日の勝利条件のホバー・フォーカス

手順と期待する結果:

1. 今日の勝利条件の枠にマウスを乗せる。枠が金色に強まり、背景が少し明るくなり、1px 浮く。マウスを外すと元に戻る。
2. 勝利条件を達成済み(チェックを入れる)にして、もう一度マウスを乗せる。達成済みでも同じ反応をする。
3. Tab キーで勝利条件の本文に移る。マウスを乗せたときと同じ反応と、本文の黄色い輪が出る。
4. 枠の空いている所(トロフィーやラベルの近く)をクリックしても、編集は始まらない。本文をクリックしたときだけ、編集が始まる。

## 3. インストーラーでの実インストールと起動

**注意**: インストールしたアプリは、この PC の**実際のデータ**(`%APPDATA%\life-launcher`)で起動します。確認の前に、`%APPDATA%\life-launcher` を別の場所へバックアップしてください。また、インストーラーは、この PC のインストール情報(「アプリの追加と削除」の登録)を書き換えます。

手順:

1. 起動中の Life Launcher があれば、完全に終了する。
2. `Life-Launcher-v1.4.0-windows-x64-setup.exe` を起動し、画面の案内に従ってインストールする。
3. インストール後、アプリが起動し、メイン画面が出る。設定と記録が保たれている。

期待する結果:

- セットアップ画面が日本語で、サイドバー画像が歪まず表示される。
- インストールが完了し、アプリが起動できる。
- 「アプリの追加と削除」から Life Launcher をアンインストールできる(確認後に不要なら)。
