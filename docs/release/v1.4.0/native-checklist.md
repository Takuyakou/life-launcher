## 1. 4つの見出しの枠、名前と件数の間、説明の文字

手順:

1. 設定 > 表示 で、メイン表示サイズを「標準」「大」「特大」の順に切り替える。
2. メイン画面の4つの見出し(「今日の3件」「次の一手」「やりたいこと」「今日の実行」)を見る。

期待する結果(「標準」「大」「特大」のすべて):

- 4つの見出しに、細い枠がある(マウスを乗せると、枠が少し明るくなり、背景が少し明るくなる)。
- 名前(「今日の3件」など)のすぐ後ろに件数(「1 / 3 完了」「5件」など)がある。名前と件数の間が、4つの見出しで同じ。
- 件数のすぐ後ろに、説明の文字がある。4つの説明の文字の大きさ・色が同じで、表示サイズを大きくすると説明の文字も大きくなる。
- 見出しの高さ、右端の「＋ プロジェクト」「…」「自動」の位置は変わっていない。

## 2. 十字キーで見出しへ移ったときの黄色い四角

手順:

1. 十字キー(または Tab)で、「今日の3件」「次の一手」「やりたいこと」「今日の実行」の見出しへ順に移る。
2. 見出しの中の「＋ プロジェクト」「…」へ移る。

期待する結果:

- 見出しへ移ると、見出し全体を囲む黄色い四角が **1つだけ** 出る(内側にもう1つ四角が出ない)。
- 「＋ プロジェクト」「…」へ移ると、そのボタンの黄色い輪だけが出て、見出し全体の四角は出ない。

## 3. 勝利条件が未入力のときの光り方

手順:

1. 勝利条件を空にして(本文を消して)、アプリを完全に終了し、起動し直す。
2. 起動直後の勝利条件の枠を見る。
3. 勝利条件の枠(「今日はこれができれば勝ち」)にマウスを乗せる。
4. そのまま Enter キーを押す。
5. 起動し直して、起動直後に Tab キーなどのキーを押す。

期待する結果:

- 起動直後、勝利条件の枠が光っていない(枠は金色に強まらず、浮かず、黄色い輪も出ない)。
- マウスを乗せても、文字も枠も変わらない。
- Enter を押すと、入力欄になり、そのまま入力を始められる。
- 1文字入力すると、枠が金色に強まる(入力済みと同じ反応)。全部消すと、また光らなくなる。
- 起動直後にキーを押すと(Tab など)、本文のまわりに黄色い輪が出る。

## 4. 勝利条件が入っているときのマウスの反応とキーボードの輪

手順と期待する結果:

1. 勝利条件を入力しておく。枠にマウスを乗せる。枠が金色に強まり、背景が少し明るくなり、1px 浮く。マウスを外すと元に戻る。
2. 勝利条件を達成済み(チェックを入れる)にして、もう一度マウスを乗せる。達成済みでも同じ反応をする。
3. Tab キーで本文に移る。**内側の黄色い輪だけ** が出て、枠は金色に強まらない。チェックボックスへ移っても同じ。
4. 本文をクリックして編集する。編集中は、枠が金色に強まったままになる。
5. 枠の空いている所(トロフィーやラベルの近く)をクリックしても、編集は始まらない。本文をクリックしたときだけ、編集が始まる。

## 5. インストーラーでの実インストールと起動

**注意**: インストールしたアプリは、この PC の**実際のデータ**(`%APPDATA%\life-launcher`)で起動します。確認の前に、`%APPDATA%\life-launcher` を別の場所へバックアップしてください。また、インストーラーは、この PC のインストール情報(「アプリの追加と削除」の登録)を書き換えます。

手順:

1. 起動中の Life Launcher があれば、完全に終了する。
2. `Life-Launcher-v1.4.0-windows-x64-setup.exe` を起動し、画面の案内に従ってインストールする。
3. インストール後、アプリが起動し、メイン画面が出る。設定と記録が保たれている。

期待する結果:

- セットアップ画面が日本語で、サイドバー画像が歪まず表示される。
- インストールが完了し、アプリが起動できる。
- 「アプリの追加と削除」から Life Launcher をアンインストールできる(確認後に不要なら)。

### 5. で分かったこと(オーナーの報告、2026-10-31)

インストールと起動はできた。ただし、何もインストールされていないはずの PC で、インストーラーに「インストールする前にアンインストールする」の選択肢が出た。それを選ぶと「アンインストールできません。」と出て、選択画面に戻った。

調査(Tauri の NSIS テンプレート `installer.nsi` の `PageReinstall` / `PageLeaveReinstall`):

- この選択画面は、レジストリの `Software\Microsoft\Windows\CurrentVersion\Uninstall\Life Launcher` に以前のインストールの情報(既定値か `UninstallString`)があるときだけ出る。本体のフォルダーを手で消したなどで、登録情報だけが残っていたと考えられる。
- 「インストールする前にアンインストールする」は、登録されている古いアンインストーラーを実行する。それが無いと失敗し、「アンインストールできません。」と出て選択画面に戻る。「アンインストールしない」を選べば普通にインストールできる。
- Tauri 標準のインストーラーの動きで、v1.4.0 の変更とは関係ない。インストーラーで普通に入れた v1.3.4 から更新する場合は、アンインストーラーが残っているので起きない。

停止の条件には当たらない。既知の制限(`FINAL-RELEASE-DECISION.md` の 11.)と、次の版で行うこと(同 13.)に書いた。リリースノートには書かない。
