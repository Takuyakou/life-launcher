# Life Launcher v1.4.0

「決めたら迷わず実行でき、実行中も完了後も表示が一貫している」ことを目標に、メイン画面の表示の不整合と強弱を整えました。機能の追加やデータ形式の変更はありません。

## 今やる一手と今日の3件

- 今やる一手は、今日の3件に入っていて未完了の次の一手があれば、それを優先して示します。理由には「今日の3件に入っている一手です」と表示します。今日の3件がない日や、すべて完了した日は、従来の選び方のままです。
- 今やる一手から開始しても、今日の3件から開始しても、両方が「実行中」の表示になります。実行中は、残り時間(計測のときは「計測中」)と「一時停止」「終了」を同じ並びで表示します。
- 実行中の項目は、ボタン・右クリック・ドラッグのどの方法でも今日の3件から外せません。
- 「他の一手」で選んだ一手は、今日の3件の変更で並びが変わっても、別のプロジェクトに入れ替わりません。

## タイマー

- サイドバーのTimer、拡大タイマー、ミニタイマーに、いま取り組んでいる行動の文を表示します。長い文は、サイドバーと拡大タイマーでは2行まで、ミニタイマーでは1行までで省略し、全文はホバーで確認できます。
- 待機中のミニタイマーで、見出し・時計・状態が重なる不具合を直し、「待機中」の重複をなくしました。
- 満了時の確認ダイアログの見出しに、行動の文を表示します。
- 待機中のサイドバーTimerは、時計の色を中立色にし、重複していた「通常タイマー」の表示を1つにしました(文字の大きさは変わりません)。

## 見た目

- 表示サイズ「大」「特大」で、今日の勝利条件の文字が標準より小さくなる不具合を直しました。
- 追加・編集・設定のボタンは中立色、保存・決定は緑、キャンセルと削除系は赤、実行中・勝利条件・フォーカスは黄色、というように色の役割をそろえました。「バックアップから復元」は赤にしました。
- 役割のない枠線(上部メニューの外枠、セクションの見出しバー、補助ボタンなど)を減らしました。ボタンの押せる範囲は小さくなっていません。
- 「今日やるものを選ぶ」画面で、候補が4行以上見えるようにしました。

## メイン画面・ダイアログ・設定・記録

- 今日の3件の見出しで、件数の二重表示をやめ、「1 / 3 完了」だけを表示します。
- 次の一手のカードのボタンは「編集」(今の文を直す)、「…」メニューは「別の行動に入れ替える」(やりたいことなどから替える)に名前を分けました。次の一手のカードのメニューから「プロジェクトを管理」を外しました(プロジェクトのメニューには残っています)。
- 開いたサイドバーのグループにボタンがないときは「見出しを右クリックしてボタンを追加」と案内します。
- ダイアログの英語の小見出しを統一しました(やりたいことの編集は`Wishlist`、辞書の設定は`Dictionary`)。
- 設定で、「日付切替時刻」に単位「時」を表示し、「ミニモード」の表記を「ミニタイマーを使う」にそろえました(設定の保存形式は変わりません)。ショートカット欄の高さをそろえ、メンテナンスタブの先頭に「このタブの操作は押すとすぐ実行されます。保存は不要です。」を表示します。
- 記録画面は、メインへ戻るボタンを上部メニューの1つにまとめ、上部メニューをスクロールしても表示し続けます。「以前のメモ」は矢印と日数(例: 以前のメモ（3日）)で開閉を示します。

## 保守・セキュリティ

- 依存ライブラリの脆弱性に対応しました(DOMPurifyを`3.4.17`へ更新するなど)。設定の読み込みの互換性は自動テストで確認しています。
- 画面の自動テストに、13画面の画像比較と、今やる一手・今日の3件それぞれから始めて完了まで進む流れのテストを追加しました。

## v1.3.4から更新する方へ

- config schemaは`3`のままで、設定データの形式はv1.3.4から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.4.0-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.4.0-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.4.0-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

## 既知の制限

- UIは日本語中心で、英語対応は主に上部ツールバーなどの一部です。
- URLはWindowsの既定ブラウザで開きます。
- ブックマーク名の取得は、ローカルのブラウザープロファイルを読める場合に限ります。
- HTML手順書は、静的なHTML/CSSと登録したフォルダー内の相対assetだけを表示します。JavaScriptに依存する画面、フォーム、入れ子のフレーム、外部のassetは、安全のため動作しません。
- 画面の確認は、開発環境のWindows(Chromium)での画像比較と、ビルド済みアプリでの確認を組み合わせています。表示倍率やフォントが異なる環境では、折り返しの位置などが少し違う場合があります。

[Web Demo](https://life-launcher-web.takuyakou.workers.dev)は、合成データを使って中心的な流れを試せるブラウザ版であり、Windows製品版の完全移植ではありません。Web Demoは別公開工程であり、この本体更新と同時に更新されるものではありません。v1.4.0の変更(今やる一手での今日の3件の優先、件数表示、ボタン名など)は、Web Demoにはまだ反映されていません。
