## Packaging fix

The first RC build failed because `RUSTFLAGS` split the source remap argument at whitespace in the worktree path. Both Windows packaging scripts now pass the two remap arguments through `CARGO_ENCODED_RUSTFLAGS`, separated by Cargo's unit separator. The same path-with-spaces checkout then produced all expected artifacts.
