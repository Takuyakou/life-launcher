### Fixed advisory

初回 `cargo audit` は `quick-xml 0.39.4` のHigh advisory 2件（RUSTSEC-2026-0194 / RUSTSEC-2026-0195）で失敗した。依存経路は `tauri-utils 2.9.3 -> plist 1.9.0 -> quick-xml 0.39.4`。

安全なupstream更新として `plist 1.10.1` へlockfile更新し、`quick-xml 0.42.0` と `base64 0.23.1` を取得した。overrideや未検証patchは使用していない。更新後の `cargo audit` はexit 0。

残るallowed warningは、unmaintained 6件と、全target依存に含まれるunsound warning 2件（`event-listener 5.4.1`、Linux GTK系の `glib 0.18.5`）。現行Windows releaseの阻害とは判定しないが、Tauri upstream更新時に追跡する。
