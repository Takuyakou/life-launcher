# Life Launcher v1.4.1

v1.4.0 の使い心地を整える修正版です。タイマーの通知と時計の不具合、記録画面と見出しの見た目、インストーラーの案内、設定画面のキーボード操作を直しました。機能の追加やデータ形式の変更はありません。

## タイマー

- タイマーの開始・一時停止のときに右下に出ていた通知(「タイマーを開始しました」「タイマーを一時停止しました」)をやめました。「記録しました」「1分未満なので記録しませんでした」などの記録・警告・失敗の通知は、今までどおり出ます。
- 一時停止と再開を素早く何度も押すと、時計が巻き戻ることがあった不具合を直しました(サイドバーのTimer、拡大タイマー、ミニタイマーとも)。

## 見た目

- 表示サイズ「大」「特大」で、メイン画面と記録画面を行き来すると上部メニューの大きさが変わっていたのを、同じ大きさにそろえました。
- 記録画面の見出しの右側の文字(「プロジェクト別(今週)」の日付、「すべての記録」、「完了した項目」の件数、「今週の重点」の n/3)が右に詰まりすぎないよう、すぐ下の枠の中の文字とそろえました。
- 今日の勝利条件が未入力のときも、マウスを乗せると枠だけが金色に反応するようにしました(「今日はこれができれば勝ち」の文字は光りません。起動直後は光りません)。
- メインの4つの見出し(今日の3件・次の一手・やりたいこと・今日の実行)で、件数の始まりを縦にそろえました(標準・大・特大)。

## 設定画面のキーボード操作

- 設定画面で、十字キーだけですべての項目に移れるようにしました。今までは、数字の欄に入ると十字キーが数字の増減に使われて、ほかの項目に移れませんでした。
- 数字の欄は **Enter で編集を始め**(中身が全部選ばれます)、↑↓ で数字を増減し、Enter で決めます。Esc で編集前の値に戻ります(設定画面は閉じません。もう一度 Esc で今までどおり閉じます)。
- チェックボックスは Enter で切り替え、メイン表示サイズは ←→ で移って Enter で選べます。
- 入力欄にフォーカスがあるだけのときは黄色い輪(カーソルなし)、編集しているときは今までの入力欄の見た目(カーソルあり)で見分けられます。
- 設定画面の中だけの変更です。ほかの画面とダイアログの十字キーは変わりません。

## インストーラー

- 以前のインストールの情報だけが残っている PC で、「インストールする前にアンインストールする」を選ぶと出る「アンインストールできません。」を、原因と対処が分かる案内に変えました。Life Launcher を終了してからやり直すか、「アンインストールしない」を選ぶとインストールできます。設定と記録は消えません(日本語・英語)。

## 内部の整理

- 使っていないスタイル(CSS)を整理しました。見た目の変化はありません。

## v1.4.0から更新する方へ

- config schemaは`3`のままで、設定データの形式はv1.4.0から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.4.1-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.4.1-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.4.1-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

## 既知の制限

- UIは日本語中心で、英語対応は主に上部ツールバーなどの一部です。
- URLはWindowsの既定ブラウザで開きます。
- ブックマーク名の取得は、ローカルのブラウザープロファイルを読める場合に限ります。
- HTML手順書は、静的なHTML/CSSと登録したフォルダー内の相対assetだけを表示します。JavaScriptに依存する画面、フォーム、入れ子のフレーム、外部のassetは、安全のため動作しません。
- 画面の確認は、開発環境のWindows(Chromium)での画像比較と、ビルド済みアプリでの確認を組み合わせています。表示倍率やフォントが異なる環境では、折り返しの位置などが少し違う場合があります。
- スクリーンリーダーは、タイマーの開始・一時停止を自動では読み上げなくなりました(通知をやめたため)。ボタンの表示は変わりません。

[Web Demo](https://life-launcher-web.takuyakou.workers.dev)は、合成データを使って中心的な流れを試せるブラウザ版であり、Windows製品版の完全移植ではありません。Web Demoは別公開工程であり、この本体更新と同時に更新されるものではありません。v1.4.0以降の変更(今やる一手での今日の3件の優先、件数表示、ボタン名、タイマーの通知など)は、Web Demoにはまだ反映されていません。
