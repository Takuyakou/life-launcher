# Life Launcher v1.6.4

閉じる時の動きを開く時とそろえ、選ぶ欄の見た目を整え、アプリの内部と文書を整理した版です。今までの設定や実行記録はそのまま使えます。

## 新しく変わったところ

- ダイアログやメニュー、検索、拡大タイマーを閉じる時も、開く時と同じ短い動きで閉じるようになりました。「動きを減らす」設定では、これまでどおりすぐ閉じます。
- プロジェクトなどを選ぶ欄の一覧が、右クリックメニューと同じ見た目になりました。選んでいる項目は金色と ✓ で分かります。

## 使いやすくなったところ

- 「元に戻す」付きの通知が、ほかの通知と同じ 4 秒で消えるようになりました(前は 5 秒)。マウスを乗せている間は消えません。
- 低い窓でも、「まとめて取り込む」が画面の真ん中に開くようになりました。
- README と全体概要を、初めて見る人に伝わる形に整えました。Web Demo への導線、CI と版のバッジ、設計の見どころを足しています。

## ダウンロード

- `Life-Launcher-v1.6.4-windows-x64-setup.exe` — 通常はこちらを使います。
- `Life-Launcher-v1.6.4-windows-x64.exe` — インストールせずに起動できます。
- `Life-Launcher-v1.6.4-windows-x64-portable.zip` — 展開して単体 EXE を起動できます。
- `SHA256SUMS.txt` — ダウンロードしたファイルの整合性を確認できます。

## 更新する前に

Life Launcher を完全に終了してください。念のため、`%APPDATA%\life-launcher` フォルダを別の場所にコピーしてから、新しいインストーラーを実行してください。
