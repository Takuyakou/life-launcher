# Life Launcher v1.3.4

Windowsインストーラーの見た目と日本語表示を整え、自動テストの整理とHTML表示用ライブラリのセキュリティ更新を行いました。

## インストーラー

- WindowsのNSISインストーラーとアンインストーラーに、専用のLife Launcherアイコンを設定しました。
- セットアップ画面のサイドバー画像をLife Launcher向けに更新しました。
- 日本語Windowsではセットアップ画面を日本語で表示します。
- カスタムヘッダー画像は使用しません。インストール後のLife Launcher本体アイコンは従来のものを維持します。

NSIS標準UIの都合により、途中画面の右側に小さなLife Launcherアイコンが表示される場合があります。

## 保守・セキュリティ

- 古い仕様の無効テスト、重複した操作確認、画像比較に使われていない撮影処理を整理しました。
- 重要な操作・データ保護・セキュリティ境界の検証を中心に、内部実装への依存を減らし、本番処理や利用者に見える結果を確認する形へ整理しました。テスト整理によるアプリ機能の追加・削除はありません。
- HTMLのサニタイズに使うDOMPurifyを`3.4.13`から`3.4.16`へ更新し、既存の脆弱性に対応しました。
- Rust依存の`event-listener`を脆弱性修正版の`5.4.2`へ更新しました。

## v1.3.3から更新する方へ

- config schemaは`3`のままで、設定データの形式はv1.3.3から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.3.4-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.3.4-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.3.4-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

[Web Demo](https://life-launcher-web.takuyakou.workers.dev)は、合成データを使って中心的な流れを試せるブラウザ版であり、Windows製品版の完全移植ではありません。変更した状態はブラウザのlocalStorageに保存し、アプリ・ファイル・URL起動は演出として確認できます。Web Demoは別公開工程であり、この本体更新と同時に更新されるものではありません。
