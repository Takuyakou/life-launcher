# Life Launcher v1.3.1

辞書での探しやすさ、登録画面と手順書ビューアーの操作、使い方ガイドを改善した更新です。

## 主な変更

### 辞書

- 辞書のアイコン表示サイズを「自動」「小」「中」「大」から選べます。
- 表示形式を「タイル」「リスト」から選べます。表示形式とアイコンサイズは別々に保存されます。
- 辞書の設定ボタンと右クリックから同じ設定画面を開けます。
- 辞書設定を開いたままでもウィンドウ外を操作でき、保存ボタンの状態色もほかの決定操作と揃えました。
- サイドバーの「辞書を開く」に本のアイコンを追加し、アイコンの大きさを整えました。ショートカットや検索の使い方は変わりません。

### ドラッグで登録

- 登録するフォルダ・ファイル・URLの名前と場所を、分かりやすく表示します。
- ごみ箱なども対象名を表示し、登録前の不要な通知をなくしました。
- 既存のグループを選ぶ操作と新しいグループを作る操作を分け、サイドバーと辞書のどちらに表示するか確認できるようにしました。
- 保存に失敗しても入力内容を残し、修正して再試行できます。

### 手順書ビューアー

- フォルダ未登録時に、フォルダ選択をキャンセルしたり選んだりすると操作が止まる問題を修正しました。
- フォルダ未登録時の操作を「フォルダを読み込む」に揃えました。
- 上部には選択中の文書で使える操作を表示します。Markdown・テキストは編集でき、HTMLは表示専用です。
- 上部のボタンでウィンドウサイズを「コンパクト」「標準」「大」「特大」の順に切り替えられます。特大は1920×1080を目安とし、画面の作業領域内に収めます。表示位置、選択中の文書、編集中の内容を保ちます。
- サイドバーと本文の境界は、ドラッグまたはキーボードで幅を調整できます。
- 右クリックと「…」からは、PC上のファイルを消さずに「登録を解除」できます。
- ブラウザで文書を開いた際の不要な成功通知をなくしました。

### 使い方ガイド

- 「3分で使ってみる」から始まる初心者向け10章へ書き直しました。
- プロジェクト、次の一手、やりたいこと、今日の3件、今やる一手を具体例と毎日の順序で説明します。
- タイマー、サイドバーと辞書、手順書ビューアー、記録、バックアップ・復元・リセットの説明を現在の画面に揃えました。
- 例を読書中心の一般的な内容へ改め、箇条書きと注釈表現を読みやすく整理しました。

### 操作と表示

- タイマーの分数を上下ドラッグするときに文字選択が残らないようにしました。
- 次の一手のカードのホバー枠を、今日の3件と同じくプロジェクトの色に揃えました。

## v1.3.0から更新する方へ

- 設定データの形式はv1.3.0から変わりません。既存の設定を引き継いで利用できます。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`を別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式           | ファイル名                                      | 用途                     |
| -------------- | ----------------------------------------------- | ------------------------ |
| Installer      | `Life-Launcher-v1.3.1-windows-x64-setup.exe`    | 通常のインストール用     |
| Standalone EXE | `Life-Launcher-v1.3.1-windows-x64.exe`          | インストールせず直接起動 |
| Portable ZIP   | `Life-Launcher-v1.3.1-windows-x64-portable.zip` | 展開して起動             |
| SHA256         | `SHA256SUMS.txt`                                | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
