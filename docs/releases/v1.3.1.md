# Life Launcher v1.3.1

辞書、Drop Register、手順書ビューアー、アプリ内Guideを整えるpatch releaseです。

## 主な変更

### 辞書

- 辞書のtile表示サイズを「自動」「小」「中」「大」から選べます。
- titlebarの設定ボタンと右クリックから同じ辞書設定を開けます。
- Mainの「辞書を開く」へwindow iconを追加しました。shortcutと検索・ページ・lock・項目起動の動作は従来どおりです。

### Drop Register

- 登録対象は内部action prefixではなく、実際のfolder、file、URLを読みやすく表示します。
- 既存groupと新規groupの選択を分け、Quickと辞書の表示先が何に向いているかを画面内で確認できます。
- 保存に失敗してもdialogと入力内容を残し、修正して再試行できます。

### 手順書ビューアー

- no-folder状態のfolder pickerをWindows標準`IFileOpenDialog`へ置き換え、cancelまたはselect後に停止する問題を修正しました。
- 空状態の入口を「フォルダを読み込む」へ統一しました。
- toolbarは選択中の対象に必要な操作だけを表示し、Markdown/Textは編集、HTMLはread-onlyとして扱います。
- ユーザー向け表記を「手順書ビューアー」へ統一しました。

### Guide

- 「3分で使ってみる」から始まる初心者向け10章へ全面的に書き直しました。
- Project、次の一手、やりたいこと、今日の3件、今やる一手を具体例と毎日の順序で説明します。
- Timer、Quick、辞書、手順書ビューアー、記録、Backup / Restore / Reset、tray終了動作を現在のUIへ同期しました。

## v1.3.0から更新する方へ

- config schemaは`3`のままで、追加migrationはありません。既存データをそのまま読み込みます。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`を別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式           | ファイル名                                      | 用途                     |
| -------------- | ----------------------------------------------- | ------------------------ |
| Installer      | `Life-Launcher-v1.3.1-windows-x64-setup.exe`    | 通常のインストール用     |
| Standalone EXE | `Life-Launcher-v1.3.1-windows-x64.exe`          | インストールせず直接起動 |
| Portable ZIP   | `Life-Launcher-v1.3.1-windows-x64-portable.zip` | 展開して起動             |
| SHA256         | `SHA256SUMS.txt`                                | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
