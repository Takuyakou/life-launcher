## 2. リリース内容

### 2.1 動的早期完了

- 短時間タイマーの基準を満たし、通常の予定時間より前にToday3を手動停止した場合、終了方法を選べるようにした。
- 左の「今日の分は完了」はSessionを保存し、対象Today3だけを完了にする。
- 右の「未完了のまま終了」はSessionを保存し、Today3を未完了のまま残す。
- Escapeと閉じる操作は未完了扱いとした。
- ダイアログの確認待ちと保存待ちはSession時間へ加算しない。
- 二重停止、二重記録、古いTimer instanceからの操作をguardした。
- 元の次の一手、やりたいこと、Project、候補、Session、完了履歴は保持する。

### 2.2 Today3と登録元の編集同期

- Today3、今日を組み立てる、次の一手、やりたいことから共通の登録元編集画面へ到達できるようにした。
- 行動文、きっかけ、Project、開始環境、手順書、短時間・通常Timerを明示的な保存時に同期する。
- Project IDとWishlist stable IDで対象を識別し、同じ文面の別項目を混同しない。
- 同じsourceのTimerが実行中または一時停止中の場合、UI入口と保存handlerの両方で編集を拒否する。
- 編集中に同じTimerが始まった場合も保存しない。
- 編集ダイアログのボタン順、Timer入力、一覧の行配置を整理した。

### 2.3 Today3と候補の解除・Undo

- 「今日の3件から外す」と「今日の候補から外す」にUndoを追加した。
- Undoは対象差分だけを戻し、その後の並べ替え、設定変更、Session、完了履歴を上書きしない。
- 明示的に候補から外した次の一手・やりたいことを、メニューまたはD&Dで今日を組み立てるへ戻せるようにした。
- 候補へ戻した項目はToday3へ自動採用しない。

### 2.4 一覧・メニュー・Toast

- Today3と今日を組み立てるへ右クリック・省略メニューを追加した。
- `Shift+F10`とキーボードフォーカスからも同じ操作へ到達できるようにした。
- 次の一手・やりたいことは件数に応じて、0〜5件は全件、6〜19件は先頭5件と展開、20件以上は10件単位のページ表示へ切り替える。
- 今日を組み立てるは従来どおり5件単位を維持した。
- 右下ToastをWarm Rich表示へ統一した。
- 通常Toastは4秒、Undo付きToastは8秒表示する。
- Toastのホバー、フォーカス、document非表示中は残り時間を停止する。
- 進捗表示を0%から100%へ進む向きに統一し、同時表示は最大3件とした。

### 2.5 Cross-section D&D

- 今日を組み立てるの候補をToday3へD&Dできるようにした。
- 明示除外済みの登録元を今日を組み立てるへD&Dで戻せるようにした。
- 6pxのdrag thresholdを超えた直後から、有効な移動先を黄色で強調する。
- Today3は黄色2px枠、薄い背景、点線overlayと「↓ ここにドロップして『今日の3件』に追加」を表示する。
- 今日を組み立てるも同じ黄色の導線とoverlayを使用する。
- overlayをabsolute配置とし、表示時にページや後続sectionの高さを変えない。
- drop位置へ挿入線を表示し、500msの一時展開とedge scrollへ対応した。
- pointermove中は永続保存せず、成功したdrop時だけ保存する。
- 保存前に日付、source、重複、3件上限、active Timerを再検証する。
- 保存失敗時は元の表示と順序へrollbackする。

### 2.6 Timer・完了フィードバック・UI調整

- 勝利条件、個別Today3、正確な3/3完了、今やる一手へ、保存成功後だけ短い完了フィードバックを表示する。
- Today3の待機中Timerボタン幅を調整した。
- サイドバーの待機中Timer分数を上下D&Dで変更できるようにした。
- Timer実行中・一時停止中は分数変更を拒否する。
- Today3カード本体をdrag surfaceとし、編集はメニューから行う構成にした。
- Today3、今日を組み立てる、次の一手、やりたいことの行高、余白、hover、見出し、操作表示を揃えた。
- やりたいこと一覧の装飾的な左線を削除した。

## 3. データ互換性

- config schemaはv1.1.0と同じ`2`である。
- v1.1.0からv1.2.0への追加migrationはない。
- 既存の登録、Today3、Session、完了履歴を引き続き使用する。
- 通信、Tauri capability、permission、dependency構成はv1.1.0から変更していない。
- v1.0.0から直接更新する場合、source keyがない古いToday3の完了状態が未完了へ戻る既知の制約は残る。Sessionは削除しない。

- Windows Installer、Standalone EXE、Portable ZIP、SHA256SUMSを一括生成する既存処理をv1.2.0で実行した。

- 子PowerShell scriptの成否判定を`$LASTEXITCODE`依存から`$?`へ変更し、`-SkipBuild`実行時の誤判定を修正した。
- Release Candidateの保存先がrepository外へ逸脱しない既存guardを維持した。
