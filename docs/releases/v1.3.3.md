# Life Launcher v1.3.3

サイドバーへの登録、キーボード操作、今やる一手とタイマー、今日の記録を改善した更新です。

## 主な変更

- サイドバーの右クリックからファイル・フォルダー・URLを追加できるボタン作成画面を用意しました。登録元を切り替えても入力途中の内容を保持します。空のグループも表示できます。
- サイドバー、メイン画面、辞書、設定、メニュー、左下の通常タイマーをキーボードで移動しやすくしました。「今日の勝利条件」はEnterで編集・確定し、Escで編集を抜けられます。
- 実行中のタイマーをメイン画面内で拡大表示できます。次の一手ごとに自動表示も設定できます。
- 今やる一手の完了表示を、次の候補を見るまで保持します。5分タイマーの満了後に「続ける」を選び、通常タイマーから終了した場合も、元の一手の完了が表示されます。
- 同じ次の一手へのドラッグによる「やりたいこと」の重複、サイドバーの右クリック位置、アプリアイコン等の誤登録を修正しました。
- 日付が変わった後やスリープ復帰後の「今日」の表示を更新し、記録画面の固定タブがスクロール中に透ける問題を修正しました。ショートカット競合時の案内も分かりやすくしました。

## v1.3.2から更新する方へ

- 設定データの形式はv1.3.2から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`を別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.3.3-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.3.3-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.3.3-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
