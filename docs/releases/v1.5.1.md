# Life Launcher v1.5.1

細かい所を整えた版です。新しい機能はありません。今までのデータはそのまま使えます。

## 直した事

- 使い方で左の項目を押した時に、上の見出しが見えなくなっていたのを直しました。
- 今週を決める画面で、先週の記録が無い時の表示を整えました。
- 検索の窓が開いている時に、Esc で閉じられない事があったのを直しました。
- 「予定時間になりました」の画面を見やすくしました。何の予定時間だったかが、プロジェクト・やる事・予定の分数でひと目で分かります。
- サイドバーの見出しを開いたり閉じたりする時に、下の見出しが一瞬ずれて見えたのを直しました。
- タイマーの実行中に出る「一時停止」「終了」のボタンを、字が窮屈に見えない幅にし、乗せた時の動きを「5分で始める」と同じにしました。

## 中の整理

- 日時の扱いに使っている部品を、今も手入れされている物に替えました。保存される日時の書き方は変わりません。
- セキュリティの知らせ方を、GitHub の Security タブの「Report a vulnerability」にまとめました。

## ダウンロード

- `Life-Launcher-v1.5.1-windows-x64-setup.exe`:インストールして使う版(ふつうはこちら)
- `Life-Launcher-v1.5.1-windows-x64.exe`:インストールせずに使う単体版
- `Life-Launcher-v1.5.1-windows-x64-portable.zip`:単体版を ZIP にした物
- `SHA256SUMS.txt`:ダウンロードしたファイルが壊れていないかを確かめるための値

## 更新する前に

- 自動の更新はありません。Life Launcher を完全に終了してから、新しい版をインストールしてください。
- 念のため、エクスプローラーのアドレス欄に `%APPDATA%\life-launcher` と入れて開き、そのフォルダを丸ごと別の場所にコピーしておいてください。
