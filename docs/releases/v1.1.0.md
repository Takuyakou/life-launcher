# Life Launcher v1.1.0

> 公開前の原稿です。リリース日は未確定で、以下の配布物はまだ公開されていません。

「登録しておくこと」「今日やること」「実行した記録」を整理し、今日の一手を選び直しやすくした更新です。

## 主な変更

### 今日の3件を、実行と選び直しのためのカードに

- プロジェクト色付きのカードで、短時間・通常タイマーをすぐ開始できます。画面幅に応じて3列・2列・1列に並びます。
- 完了は予定時間まで実行し、終了を確定した項目だけに付きます。途中終了は完了扱いになりません。
- 3件すべてが完了すると「次の3件を選ぶ」が表示されます。次の項目を自動で補充せず、自分で次の枠へ進めます。
- カード左下と右クリックに「今日の3件から外す」を追加しました。確認ダイアログなしで今日への採用だけを解除し、元の次の一手・やりたいこと・候補・実行記録は残します。
- 対象Today3のタイマーが実行中・一時停止中・満了確認中の間は、その項目を外せません。完了済みの項目は外せます。
- 未設定の「+ きっかけ」はタイマー上の専用領域へのホバー、またはキーボードフォーカスで表示します。設定済みのきっかけは同じ位置に常時表示します。
- D&D中は掴んだカードと黄色の挿入位置を表示し、保存に失敗した場合は元の順序へ戻します。

### 登録元を残して、今日やることを選ぶ

- 「今日を組み立てる」は次の一手とやりたいことから候補を集め、5件ずつ表示します。「今日へ」で今日の3件へ採用しても、元の登録は残ります。
- 次の一手の右クリックからも「今日へ」を選べます。
- Builderの「今日の候補から外す」は、その日だけ候補を除外する別の操作です。同じ候補の今日の項目も外れますが、元の登録は残り、日付切替で候補の除外が解除されます。
- 採用時の本文・手順書・開始環境の参照・タイマー分数をToday3へ保持します。後からプロジェクトのタイマー時間を変更しても、採用済みの分数は変わりません。
- やりたいことは小型ダイアログから追加できます。同じ文面の項目も別々のIDで管理します。

### 登録の完了と実行記録を区別

- 次の一手・やりたいことの「完了にする」と「削除」を区別し、記録画面に「完了した項目」を追加しました。
- 次の一手を完了してもプロジェクト自体は残ります。やりたいことを完了すると一覧から外れ、完了時点の内容が履歴に残ります。
- Today3のタイマー満了は、元の登録そのものを完了・削除する操作ではありません。実行記録と登録の完了履歴は別に扱います。

### 辞書と開始環境を使いやすく

- 辞書を開いた直後の矢印キー移動、検索中のキー操作、D&Dの表示を改善しました。
- 複数モニターでは、Life Launcher本体がある画面に辞書を表示します。
- Quickと辞書の間で登録を移しても、起動アクションは保持します。
- プロジェクト・やりたいことの開始環境を、サイドバー・辞書から検索して選べます。新規選択は最大2件で、保存済みの3件以上の登録を勝手に切り捨てません。
- 開閉バーのクリック範囲、確認ダイアログのボタン順、記録画面とアプリ内ガイドを整えました。

## v1.0から更新する方へ

**更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。**

- v1.0の今日の3件には、新しい識別用のsource keyがありません。移行時にこれを補完する項目は、既存の「完了」が「未完了」に戻ります。これは今回の移行仕様です。
- この変更でSessionの実行記録を削除することはありません。以前の完了表示を確認したい場合に備え、更新前のバックアップを残してください。
- この移行だけでは、設定を書き換える前の自動バックアップは保証されません。
- やりたいことのIDやToday3のタイマー分数など、旧データにない項目は読み込み時に補完します。
- 自動アップデーターはありません。正式公開後の配布物を使用して更新してください。

## 配布予定ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.1.0-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.1.0-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.1.0-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 現在のビルドはコード署名されていません。正式配布物が未署名の場合、Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。
- 開発依存の`js-yaml`を`4.3.2`へ更新しました。これは開発ツールの依存更新で、アプリへの機能追加ではありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
