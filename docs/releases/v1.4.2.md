# Life Launcher v1.4.2

Windowsの白いタイトルバーをなくし、アプリと一体のヘッダーにしました。あわせて、タイマーの進み具合を窓の上端の細い線で示し、手順書ビューアーを十字キーで操作できるようにし、「使い方」を分かりやすくしました。データ形式の変更はありません。

## ウィンドウ(タイトルバー)

- メイン画面と手順書ビューアーで、Windows標準の白いタイトルバーをやめました。窓の最小化・最大化・閉じるは、上部メニューの右端に並ぶアプリのボタンで行います。
- 上部メニューのボタン以外の所、本文の上端の余白、サイドバーの上の「Life Launcher / Quick」の表示をドラッグすると、窓を動かせます。ダブルクリックで最大化と元に戻すを切り替えられます。
- 窓の端と角をつかんで大きさを変えられます。最大化したときは作業領域に収まります。
- 窓の幅を狭めると、上部メニューの文字は入りきらないときだけアイコンに変わります。隠れたボタンも、マウスを乗せたときの説明と読み上げの名前は残ります。
- ダイアログを開いたままでも、右上の窓のボタンはマウスで押せます。
- 更新後の初回の起動でも、白いタイトルバーは戻りません(窓の位置・大きさは今までどおり引き継ぎます)。

## タイマーの進み具合の線

- メイン画面の窓の上端(左端から右端まで、高さ3px)に、タイマーの進み具合を示す細い線を出すようにしました。メイン画面と記録画面のどちらを見ていても出ます。
- 実行中は黄色で、左から少しずつ伸びます。一時停止中は橙で、その位置に止まります。予定時間になると100%のまま残り、終了すると消えます。
- 時間を決めない「計測」と待機中は出ません。
- 「続ける(+15分)」で予定時間を延ばすと、線の長さも計算し直します。
- 線は飾りです。窓のボタンやドラッグの操作を邪魔しません。

## 手順書ビューアーの十字キー操作

- 手順書ビューアーを開くと、一覧にフォーカスが入ります。マウスで押さなくても、すぐ十字キーで動かせます。
- 一覧は↑↓で移動、→←でフォルダーを開く・閉じる、Enterでファイルを開きます(↑↓では開きません)。
- ファイルの行で→を押すと本文へ移ります。本文は↑↓で少しずつ、PageUp・PageDownで1画面ずつ、Home・Endで先頭と最後へスクロールします。←を押すと一覧へ戻ります。HTMLの手順書も同じです。
- 検索欄が空のときの↓で一覧へ、一覧の先頭で↑を押すと検索欄へ戻ります。
- 上部のボタンの間は←→で移れます(端で止まります)。
- 「手順書ビューアーのサイズを切り替える」など、今までの操作は変わりません。

## 使い方(アプリ内ガイド)

- 文章を分かりやすくしました。画面のボタンやチェックボックスの名前(「開始時に手順書を開く」「バックアップから復元」など)に合わせています。
- 今日の3件の並べ替えと外し方、バックアップから戻すときの動きなど、詰め込まれていた説明を分けました。
- 下の「閉じる」を赤にしました(キャンセル・閉じるは赤、保存・決定は緑)。

## v1.4.1から更新する方へ

- config schemaは`3`のままで、設定データの形式はv1.4.1から変わりません。既存の設定、今日の3件、実行記録を引き継げます。
- 窓の位置と大きさの保存も引き継ぎます。標準のタイトルバーは戻りません。
- 更新前にLife Launcherを完全終了し、`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてバックアップしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.4.2-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.4.2-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.4.2-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

## 既知の制限

- UIは日本語中心で、英語対応は主に上部ツールバーなどの一部です。
- ウィンドウ: Windows 11で、最大化ボタンにマウスを乗せたときに出る配置の選択(スナップレイアウト)は出ません。アプリで作ったボタンのためです。画面の端へドラッグしたときのスナップと Win+Z はWindowsの機能ですが、この版では動作を確かめていないため、使える前提にしていません。
- URLはWindowsの既定ブラウザで開きます。
- ブックマーク名の取得は、ローカルのブラウザープロファイルを読める場合に限ります。
- HTML手順書は、静的なHTML/CSSと登録したフォルダー内の相対assetだけを表示します。JavaScriptに依存する画面、フォーム、入れ子のフレーム、外部のassetは、安全のため動作しません。HTMLの手順書は表示だけで、アプリ内では編集できません。
- 画面の確認は、開発環境のWindows(Chromium)での画像比較と、ビルド済みアプリでの確認を組み合わせています。表示倍率やフォントが異なる環境では、折り返しの位置などが少し違う場合があります。
- タイマーの開始・一時停止は、スクリーンリーダーでは自動で読み上げません(通知をやめたため。画面のボタンと時計の表示で示します)。

[Web Demo](https://life-launcher-web.takuyakou.workers.dev)は、合成データを使って中心的な流れを試せるブラウザ版であり、Windows製品版の完全移植ではありません。Web Demoは別公開工程であり、この本体更新と同時に更新されるものではありません。v1.4.2の変更(一体型タイトルバー、窓の上端のタイマーの線、手順書ビューアーの十字キー操作)は、Web Demoには関係しません。
