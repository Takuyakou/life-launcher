# Life Launcher v1.5.0

画面を作り直しました。上の段・サイドバー・検索・メイン画面・今日やるものを選ぶ画面・タイマー・終わりの確認・取り込み・使い方まで、見た目と操作をそろえています。設定ファイルの形(ersion 3)は変わりません。はじめての案内のために、設定に印(irstRunDoneAt)を 1 つ足しました(前の版で開いても壊れません)。

## 画面の作り直し

- 上の段は、日付の見出しと [自動起動] [記録 / 手順書 / 設定] [窓のボタン] に整理しました。検索は真ん中に移し、虫めがねのボタンと Ctrl+F で開きます。
- サイドバーの見出しは、開け閉めが滑らかになりました。
- 今やる一手の行動を大きく出し、始めるボタンをその文の下に並べました。今日の3件に「いまここ」の札を出します。次の一手は 1 行ずつの一覧にし、左にプロジェクト名、真ん中に行動、右に「＋ 今日へ」「編集」を横に並べました。
- やりたいことは、プロジェクトごとのまとまりと「▷ 次の一手にする」で見やすくしました。
- 今日やるものを選ぶ画面は、左に候補、右に今日の3件の枠があります。ドラッグか Alt+↑↓ で並べ替え、決定で 1 回だけ保存します。閉じるときに変わっていたら、捨てるかを確かめます。
- 次の一手の編集は、ボタン・手順書・タイマーの分数を 1 つの画面にまとめました。
- 左下のタイマーは 4 つの状態で段をそろえ、待機中も「今日 N分・N回」とミニのボタンを出します。拡大タイマーは、残り時間と終わる時刻を大きく出します。

## 検索・キー

- 一手・ボタン・手順書を、ひらがな・カタカナ・全角・半角・英字の大小を同じに扱って探せます。Enter で短時間、Shift+Enter で通常の分数で始められます。
- 行にフォーカスして Enter で始める（やりたいことは次の一手にする）、F2 で編集、Delete で削除が効きます。Delete は、次の一手の行では「次の一手を未設定にする」（プロジェクトは消しません）、やりたいことの行では削除、今日の3件の札では今日から外す、です。
- 右クリックのメニューに、効くキーの札を出しました。T で今日の3件に入れられます。
- トーストに残り時間の線が付き、失敗のトーストは × で閉じるまで残ります。Ctrl+Z で一番新しい「元に戻す」が効きます。
- 使い方に「キーの一覧」を足しました。

## はじめての起動

- プロジェクトも今日の3件も空のときは、「まず、1つだけ始めましょう」の案内を出します。続けたいことと最初の一手を入れて「5分で始める」を押すと、プロジェクト 1 つと次の一手 1 つを作って、5 分のタイマーを始めます。

## 文字と動き

- 字を Inter と Noto Sans JP にしました（同梱、SIL OFL 1.1）。
- 動きは Motion（MIT）で付けています。Windows の「アニメーションを表示しない」では動かず、終わりの形になります。

## 直した不具合

- やりたいことの `sourceWishlistId` が保存で消えることがある不具合を直しました。
- 次の一手の鮮度の判定を、`reviewed_at` と `updated_at` の新しい方で見るように直しました。

## アップデートの前に

- アプリを完全に終了し、`%APPDATA%\life-launcher` を別の場所にコピーしてバックアップしてください。自動アップデーターはありません。
- 設定ファイルの形（`version` 3）は変わりません。古い版に戻すと、新しい版で足した設定が失われることがあります。
