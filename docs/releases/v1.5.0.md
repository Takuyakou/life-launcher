# Life Launcher v1.5.0

画面を作り直しました。上の段・サイドバー・検索・メイン画面・今日やるものを選ぶ画面・タイマー・終わりの確認・今週を決める・取り込み・使い方まで、見た目と操作をそろえています。設定ファイルの形(`version` 3)は変わりません。はじめての案内の印(`settings.firstRunDoneAt`)と、次の一手の「次はここから」(`resumeNote`)の、省略できる項目を 2 つ足しました(前の版で開いても壊れません)。

## 画面の作り直し

- 上の段は、左にロゴ、真ん中に検索、右に [自動起動] [記録 / 手順書 / 設定] [窓のボタン] の並びにしました。検索は虫めがねのボタンと Ctrl+F で開きます。今日の日付は、メイン画面の一番上に今日の勝利条件と同じ行で出します。
- サイドバーのボタンは、名前を少し小さく太い字にして行を詰め、見出しの開け閉めを滑らかにしました。
- メイン画面の中身は最大 1200px の幅で、窓の真ん中に置きました。
- 今やる一手の行動を大きく出し、始めるボタンをその文の下に並べました。今日の3件の、今やる一手と同じ札に「今やる一手」の札を出します。選んだ理由は、ふだんの言葉で出します。次の一手は 1 行ずつの一覧にし、左にプロジェクト名、真ん中に行動、右に「＋ 今日へ」を置きました(乗せると「編集」が出ます)。
- やりたいことは、プロジェクトごとのまとまりと「▷ 次の一手にする」で見やすくしました。
- 今日やるものを選ぶ画面は、左に候補、右に今日の3件の枠があります。ドラッグか Alt+↑↓ で並べ替え、決定で 1 回だけ保存します。閉じるときに変わっていたら、捨てるかを確かめます。
- 次の一手の編集は、ボタン・手順書・タイマーの分数を 1 つの画面にまとめました。
- 左下のタイマーは、待機中の右上にミニにするボタンを出しました。拡大タイマーは、残り時間と終わる時刻を大きく出します。ミニは 2 段の形にしました。

## 次はここから・見つからない物の知らせ

- 今日の3件に入っていない次の一手は、予定時間になったときの画面と次の一手の編集で「次はここから」を 1 行書いておけます。次に「今やる一手」に出たときに、行動の下に出ます。
- 今日の3件に入れた次の一手を終えると、「一手進みました」の画面で、次はどこから始めるかを選べます。
- 次の一手に付けたアプリ・フォルダ・ファイル・手順書が見つからなくなったときは、オレンジ色の「見つかりません」を出します。確かめるのは PC の中の場所だけです。
- 設定の「メンテナンス」に「リリースページを開く」を置きました(ブラウザで開くだけで、アプリは通信しません)。

## 今週を決める

- 記録の画面の「今週を決める」を作り直しました。先週の合計・動いた日・始めた回数、プロジェクトごとの時間、完了にした項目を見て、今週の重点を 3 つまで選びます。
- 14 日以上同じ次の一手のプロジェクトは「しばらく動いていないもの」に出し、「小さくする」「このまま」を選べます。
- 「先週の事実を付けてコピー」で ChatGPT や Claude に相談し、返ってきた JSON を「まとめて取り込む」で足せます。アプリから外へは何も送りません。評価や点数は付けません。

## 検索・キー

- 一手・ボタン・手順書を、ひらがな・カタカナ・全角・半角・英字の大小を同じに扱って探せます。Enter で短時間、Shift+Enter で通常の分数で始められます。
- 行にフォーカスして Enter で始める(やりたいことは次の一手にする)、F2 で編集、Delete で削除が効きます。Delete は、次の一手の行では「次の一手を未設定にする」(プロジェクトは消しません)、やりたいことの行では削除、今日の3件の札では今日から外す、です。
- 右クリックのメニューに、効くキーの札を出しました。T で今日の3件に入れられます。
- トーストに残り時間の線が付き、失敗のトーストは × で閉じるまで残ります。Ctrl+Z で一番新しい「元に戻す」が効きます。
- 使い方に「キーの一覧」を足しました。

## はじめての起動

- プロジェクトも今日の3件も空のときは、「まず、1つだけ始めましょう」の案内を出します。続けたいことと最初の一手を入れて「5分で始める」を押すと、プロジェクト 1 つと次の一手 1 つを作って、5 分のタイマーを始めます。

## 文字と動き

- 字を Inter と Noto Sans JP にしました(同梱、SIL OFL 1.1)。
- 動きは Motion(MIT)で付けています。メニュー・ダイアログ・検索の窓は開くときに少し動いて出て、今やる一手が入れ替わるときは中身が横から入ります。Windows の「アニメーションを表示しない」では動かず、終わりの形になります。

## 直した不具合

- やりたいことの `sourceWishlistId` が保存で消えることがある不具合を直しました。
- 次の一手の鮮度の判定を、`reviewed_at` と `updated_at` の新しい方で見るように直しました。
- 2 回目以降用の取り込みのプロンプトに、JSON の形式が入っていなかった不具合を直しました。
- 使い方の「タイマーと完了」に、実際の画面に無い選択肢が書かれていたのを直しました。

## アップデートの前に

- アプリを完全に終了し、`%APPDATA%\life-launcher` を別の場所にコピーしてバックアップしてください。自動アップデーターはありません。
- 設定ファイルの形(`version` 3)は変わりません。古い版に戻して保存すると、「次はここから」とはじめての案内の印は消えます。
