# Life Launcher v1.0.0

Life Launcherの最初の公開リリースです。選んだ「次の一手」を行動に移すためのWindowsデスクトップランチャーとして、Quickサイドバー、検索可能な辞書、今日のフォーカス、タイマー、セッション記録、手順ビューアを提供します。

## Download

### Installer - Recommended

通常はこちらを使用してください。

`Life-Launcher-v1.0.0-windows-x64-setup.exe`

### Standalone EXE

インストールせず直接起動する版です。

`Life-Launcher-v1.0.0-windows-x64.exe`

### Portable ZIP

ZIPを展開して使用する版です。

`Life-Launcher-v1.0.0-windows-x64-portable.zip`

## 動作要件

- Windows 10以降(x64)
- Microsoft Edge WebView2 Runtime

## 確認

配布ファイルの整合性は`SHA256SUMS.txt`で確認できます。

このリリースにはアカウント、テレメトリ、クラウド同期、自動アップデータはありません。ユーザーデータは`%APPDATA%\life-launcher`へ保存され、配布ZIPには含まれません。
