# Life Launcher v1.3.2

メイン画面を読みやすくし、見出しと操作メニューのバランスを整えた更新です。

## 主な変更

- 設定の「基本」→「表示」から、メイン表示サイズを「標準」「大」「特大」に切り替えられます。従来の見た目は「標準」で、既存の設定もそのまま使えます。
- 「大」「特大」ではメイン画面の文字、カード、操作部と表示幅を広げました。上部メニューも広い画面では本文に合わせて大きく表示します。サイドバー、記録画面、辞書、手順書ビューアー、ミニ画面のサイズは変わりません。
- 「今やる一手」「今日の3件」「次の一手」「やりたいこと」「今日の実行」の見出し位置を整え、「今日の実行」の項目を読みやすい位置に調整しました。
- メイン画面の「先週のふりかえりが見られます」という案内をなくしました。記録画面から週次ふりかえりは引き続き利用できます。

## v1.3.1から更新する方へ

- 設定データの形式はv1.3.1から変わりません。表示サイズを選んでいない場合は「標準」になります。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`を別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.3.2-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.3.2-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.3.2-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
