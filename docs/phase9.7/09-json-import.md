## 判断メモ

- プロジェクトの突合は、前後の空白を除いた名前を大文字小文字を無視して比べる。同じ名前がすでにあれば上書きせず、空の色・目標だけを補う。JSON内の同じ名前は1つにまとめ、先に出た色・目標・次の一手を残す。
- すでに次の一手があるかは、本文が空でない `nextStep` で判断する。古い実行設定が残っているだけのプロジェクトも、次の一手を入れると実行設定が混ざるため、やりたいことに入れる。
- やりたいことの重複は、同じプロジェクトIDと同じ文で判断する。プロジェクトなしのやりたいことは、プロジェクトなし同士で比べる。足さないものは理由を出す。
- プレビューの件数は、新規プロジェクト・既存プロジェクト・次の一手（入れる/やりたいことへ）・やりたいこと（足す分）・取り込めない項目。やりたいことへ回した次の一手は、次の一手とやりたいことの両方に出る。
- `.json` の読み込みは、BOMを除き、256 KBをバイト数で見て、UTF-8として読めないときは理由を返す。JSONの解析はRustの `serde_json` で行い、フロントは説明文やコードフェンスから候補を1つだけ抜く。
- ドロップの場所は、Tauriのイベントは物理ピクセル、独自ドロップ先は子HWNDのクライアント座標（物理）で届く。どちらもフロントで `devicePixelRatio` で割ってCSSピクセルにする。独自ドロップ先が複数の子HWNDに付く場合、実際に落ちた子の座標を使う。
- 取り込みのバックアップは、復元と同じ4ファイルをZIPにし、設定のバックアップフォルダが未設定でもデータフォルダに作る。取り込みのIDは `import-<時刻>-<連番>`。
- 取り込み後は設定だけを差し替える。今日の3件・実行記録・ノートは触らない。取り消しは設定だけを戻す。
- 依存関係は増やしていない。色は今あるCSS変数だけを使い、新しい色は足していない。
- ダイアログのフォーカスは開いたときにJSONの欄へ移し、閉じたら開いた場所へ戻す。背景クリックとEscapeで閉じる。
