## 完了条件ごとの結果

### 1. プロンプトを2つにし、全文は importPrompt.ts だけに置く

- `IMPORT_PROMPT_FIRST` と `IMPORT_PROMPT_REPEAT` を `src/content/importPrompt.ts` に置いた。2回目以降用は `{CURRENT_STATE}` を含む。
- 取り込み画面も使い方も、この2つをimportして使う。プロンプトの文をほかのファイルに写していない。
- 使い方では、2回目以降用の `{CURRENT_STATE}` を「(「今の内容を付けてコピー」で、ここに今のアプリの内容が自動で入ります)」に置き換えて表示する。
- JSONの形式・合わせ方・上限（256 KB、プロジェクト30件、やりたいこと100件など）は変えていない。

### 2. 取り込み画面の2つのボタン

- 「はじめて用をコピー」を押すと、`IMPORT_PROMPT_FIRST` をそのままクリップボードに入れる。
- 「今の内容を付けてコピー」を押すと、`IMPORT_PROMPT_REPEAT` の `{CURRENT_STATE}` を今のconfigから作った文に置き換えてコピーする。
- 2つ目の下に「コピーする文には、今のプロジェクト名・目標・次の一手・やりたいことが入ります。」を小さく出した。
- コピーに失敗したときは、今までどおり警告のトーストを出す。

### 3. 今のアプリの内容

`buildImportCurrentState(config)` の形:

- プロジェクトごとに、`名前(色: colorId)`。色の指定が無ければ名前だけ。
- 目標があれば `目標: ...`、次の一手があれば `次の一手: ...`、そのプロジェクトのやりたいことがあれば `やりたいこと: A / B`。
- プロジェクトに入らないやりたいことがあれば、最後に `プロジェクトなしのやりたいこと: A / B`。
- 目標・次の一手・やりたいことが無い行は書かない。プロジェクト名は今の名前をそのまま使う。
- 完了済み・実行記録・今日の3件・ボタン・手順書・パスは使わない（configのprojectsの名前・northStar・nextStep.text・colorIdと、inboxのtext/projectIdだけを見る）。
- プロジェクトもやりたいことも無いときは `(まだ何もありません)`。

テストでは、プロジェクト名がconfigと一字一句同じこと、次の一手・やりたいことが入ること、`sample-documents`・`C:\`・「完了」・「今日の3件」が入らないこと、色なし・空行の扱い、空のときの `(まだ何もありません)` を確認した。

### 4. 使い方

- 「まとめて取り込む」の章を、はじめてと2回目以降の2つの手順に分けた。
- `type: "code"`・`copyable: true` の枠で、2つのプロンプト全文を出した。2回目以降用は `{CURRENT_STATE}` を説明文に置き換えている。
- 続けて、`type: "code"`・`copyable: false` で「私の状況」の例を出した:
  `英語を話せるようになりたい。平日の夜に30分くらい使える。ベースで好きな曲を1曲弾けるようになりたい。部屋の片付けもしたいが、何から手を付けるか決まっていない。`
- 使い方の「コピー」で入る文が `importPrompt.ts` と同じで、2回目以降用は置き換え後の文になることをテストした。

### 5. 仕様書

## 判断メモ

- プロンプトの文を1か所にするため、`importPrompt.ts` の定数を使い方からimportした。使い方の2回目以降用だけは、`{CURRENT_STATE}` を説明文に置き換えて表示する（コピーする文は実際の今の内容）。
- 今の内容は、configのprojectsとinboxだけから作る。今日の3件・実行記録・ボタン・手順書・パスを参照しないので、完了済みや設定が混ざらない。
- プロジェクト名はtrimせずそのまま使う。目標・次の一手・やりたいことは前後の空白を落として空行を避けた。
- 色は `colorId` があるときだけ `(色: blue)` の形で出す。指定が無いプロジェクトは名前だけ。
- 取り込み画面の2つ目のボタンの下に説明を置き、コピーする文に何が入るかを押す前に分かるようにした。
- 使い方のプロンプトは長いため、既存のcode block（スクロール・コピー）をそのまま使った。例の枠はコピー不要なので `copyable: false` にした。
- 取り込みのJSON形式・合わせ方・上限は変えていない。今回の変更はプロンプトと使い方、コピー用の文だけ。
