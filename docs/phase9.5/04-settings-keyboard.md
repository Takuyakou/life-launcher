# P95-04 — 設定画面を十字キーと Enter で操作できるようにする

**判定: DONE**(ブランチ `feature/p95-04-settings-keyboard`、`main` = `d71f8d5`(P95-03 のマージ後)から)

## 実装内容の要約

設定画面(設定ダイアログ)の中だけ、十字キーを常に「移動」に使い、数字の入力欄は Enter で編集を始めるようにした。

- **移動の状態(既定)**: ↑↓ は、入力欄・ラジオ・チェックボックス・ボタン・タブのどれにフォーカスがあっても前・次の項目へ移る。入力欄の数字は変わらず、カーソルも動かない。←→ は同じまとまりの中で移る。
- **編集の状態**: 入力欄で Enter、入力欄のクリック、または文字を打ったときに入る。↑↓ は数字の増減(今までどおり)、←→・文字入力は入力欄の普通の動き。Enter で決めて移動の状態に戻る(フォーカスはそのまま)。Esc で編集前の値に戻して移動の状態に戻る(設定画面は閉じない。2回目の Esc で今までどおり)。Tab / Shift+Tab / ほかの場所のクリックでは、値を残して移動の状態に戻る。
- Enter: チェックボックスは切り替え、ラジオ(メイン表示サイズ)はその選択肢を選ぶ。ボタンは今までどおり押す。
- 見た目: 移動の状態の入力欄は黄色いフォーカスの輪(2px)でカーソルなし、編集の状態は輪なしで今までの入力欄の見た目(枠が強くなる)とカーソル。

## 仕組み

入力欄の編集状態は、`keyboardNavigation.ts` の中だけに持つ(1つの入力欄と、編集前の値)。編集の状態の入力欄には `data-editing` を付け、CSS はそれで見た目を切り替える。

- Esc で値を戻すときは、`value` のネイティブの setter と `input` イベントで React の `onChange` を通すので、下書き(`settingsDraft`)も戻る。
- Esc は document の keydown で `stopPropagation` するので、window 側の「設定を閉じる」の Esc 処理には届かない(編集の状態のときだけ)。
- IME の変換中(`isComposing`)の Enter は無視する。ショートカット記録中は、記録側が先にキーを止めるので影響しない。
- 設定画面の外では `.settingsDialog` の中でないとき何もしない。

## 判断メモ(指示書との違い・補足)

1. **文字を打ったら編集の状態に入る**: 指示書は Enter かクリックで編集の状態に入る。それに加えて、移動の状態で文字キーや貼り付けをした場合も、編集の状態に入れる(入る直前の値を「編集前の値」にするので、Esc で戻せる)。入力を黙って捨てるより自然なことと、既存の Playwright テストの `fill()` がそのまま動くため。Enter で編集に入るのとの違いは、中身を全部選ばないこと。
2. **設定画面に文字の入力欄はない**: 設定画面の入力欄は数字(4つ)と読み取り専用のバックアップ保存先だけ。読み取り専用の欄は編集の対象にしない(移動の状態の輪だけ出る)。IME のテストは、数字の欄に `isComposing` の Enter を送って確かめた。
3. **↑ で最初の項目から戻ると、押したタブではなく最後のタブに移る**(今までの動きのまま。DOM の順に1つ前へ移るため)。今回は変えていない。「提案」に書いた。
4. **←→ のまとまり**: 「同じ行」を厳密には判定せず、同じまとまり(グリッドなど)の中で DOM の順に前・次へ移る。

## 実機で確かめること(P95-05 の確認一覧に入れる)

- 本物のアプリ(WebView2)で、設定を開いて ↓ だけで全項目に移れること。
- 数字の欄で Enter → 全選択、↑↓ で増減、Enter で決定、Esc で戻る。
- 移動の状態の黄色い輪と、編集の状態のカーソルが、実際の画面で見分けられること。
- 日本語 IME をオンにしたまま設定画面を操作したときの Enter(数字の欄にはもともと日本語は入らない)。

## 提案

- 設定画面で、最初の項目から ↑ を押したとき、押しているタブ(選択中のタブ)に戻るようにする(今は最後のタブに移る)。
- ほかのダイアログ(次の一手・やりたいことの編集、ボタンの登録など)にも同じ考え方を広げるかどうかは、オーナー判断のとおり次の版で検討。
- 同様のキー操作をテストで確かめるときの共通のヘルパー(`focused()` など)は、今は新しいテストの中だけにある。ほかのテストでも使うなら、`tests/visual/` の共通ファイルに移すとよい。
