## 6. 保存とキャンセルの文字の大きさ(項目6)

食い違いの原因: 共通の `.primaryButton` に `font-size` がなく(16px になる)、`.secondaryButton` と `.dangerButton` は 12px だった。操作行の中の `.primaryButton` だけ 12px にした(`:where(.dialogActions, .dictionarySettingsActions, .instructionUnsavedActions) .primaryButton`)。色・太さ・高さ・余白・文言は変えていない。

実測した結果(変更前 → 変更後。保存 / キャンセル):

| ダイアログ | 変更前 | 変更後 |
| --- | --- | --- |
| 次の一手の編集 | 16px / 12px | 12px / 12px |
| プロジェクトを追加 | 16px / 12px | 12px / 12px |
| やりたいことを追加 | 16px / 12px | 12px / 12px |
| グループの名前変更 | 16px / 12px | 12px / 12px |
| ボタンを追加(Button Builder、「追加」) | 16px / 12px | 12px / 12px |
| 辞書の設定(辞書ウィンドウ) | 16px / 12px | 12px / 12px |
| 設定 | 12px / 12px | 変化なし |
| 今日やるものを選ぶ(決定 / キャンセル) | 11px / 11px | 変化なし |

測っていないが、同じ操作行(`.dialogActions`)の規則で同じ直し方になるダイアログ: プロジェクトの編集、やりたいことの編集、実行記録の追加・編集、ボタンの編集、辞書のページ追加・編集、辞書のボタン登録・編集、手順書のツリーの操作ダイアログ、手順書の選択、開始環境の選択。手順書の未保存確認(`.instructionUnsavedActions`)も同じ直し方。テストでは、実測したダイアログのうち主なものの文字の大きさと太さが同じことを確認している。

## 12. 判断メモ

- **`settings.miniMode` の使い道(停止条件の確認)**: コードと Rust を確認した。使われているのは次の3か所で、すべて「ミニタイマーを開けるかどうか」の意味だった。ほかの用途(タイマーの動作、通知、表示など)はない。
  1. `openMiniMode`:OFF のとき「設定で「ミニタイマーを使う」をオンにしてください」のトーストを出して開かない(最初は「…ミニモードを有効にしてください」だった)。上部メニューの「ミニ」ボタンと、ミニ切替のショートカット(`toggleMiniMode` を呼ぶ同じ道)の両方
  2. 上部メニューの「ミニ」ボタンの無効表示
  3. OFF になったとき、開いているミニウィンドウを閉じる処理(`hideMiniWindow`)

  指示書は「上部メニューのボタンで開けるかどうか」と書いているが、ショートカットと、開いているウィンドウを閉じる処理も同じ「使うかどうか」の意味なので、停止せず、「ミニタイマーを使う」の名前で足りると判断した。Rust 側は `miniMode` を保存と既定値にしか使っていない。
- **「辞書」の eyebrow(指示書の項目1の2か所目)は表示されない**: `src/App.tsx` の「辞書」ダイアログ(`launcherOverlay`)は `{false && launcherOverlayOpen && (…)}` で、画面に出ない古いコードだった。指示書のとおり `Launcher` → `Dictionary` に直したが、画面の見た目は変わらない。表示される辞書ウィンドウの設定の eyebrow は、もともと `Dictionary`(テストで確認)。
- **名前を変えたあとのトースト**: 最初は指示書の対象外として「ミニモード」のまま残し、提案にした。オーナーの指示で、画面に出る名前をすべて「ミニタイマー」にそろえた(14. 参照)。
- **ショートカットの補足行の高さ**: 補足行がなくなると、同じ行の欄が行の高さに合わせて伸び、入力欄が下にずれた(「メイン呼び出し」「ミニモード切替」が「辞書」より下)。欄の内側を上詰め(`align-content: start`)にして、入力欄の上端をそろえた(14. 参照)。未設定の欄は補足行の分だけ短く、行の高さは補足行のある欄が決める。
- **「時」は読み上げない**: 見た目だけの単位で、ラベルの「日付切替時刻」と値で伝わるため `aria-hidden` にした。
- **日数のかっこ**: 最初は指示書の例にそろえて半角のかっこにしたが、オーナーの指示で全角(「以前のメモ（3日）」)にした。
- **文字の大きさ12px**: 保存側を大きいキャンセル側(12px)ではなく、キャンセル側の12pxにそろえた。設定ダイアログとほかの操作行がすでに12pxだったため。16pxにそろえると、操作行の高さに対して大きすぎる。
- **日数の数え方**: 「以前のメモ」の日数は、以前のメモがある日付の数(保存済みの `notes` の日付の件数)。
