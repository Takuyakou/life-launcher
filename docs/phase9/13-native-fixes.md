### 3.1 大・特大で、今日の3件の説明文が右端に寄る

- 原因は指示書のとおり。`.todaySectionBar` を共通ルール(`:is()` の中)と専用ルールの両方に書いていて、共通ルールの詳細度が勝っていた。
- 直し方: 大・特大の共通ルールの `:is()` から `.todaySectionBar` を外した(`!important` なし)。専用ルール `132px 34px max-content minmax(0, 1fr)`(特大は `144px 38px …`)だけが残り、標準と同じ構造になった。
- 計算後の列(1080×680、`createFullTodayFixture`):

| 表示サイズ | 修正前の `.todaySectionBar` の列 | 修正後 | 説明文の左端(修正前 → 後) |
| --- | --- | --- | --- |
| 標準 | `120px 30px 18.7px 581.3px` | 変化なし | 461.7px(変化なし) |
| 大 | `132px 34px 362.2px 221.8px` | `132px 34px 23.1px 560.9px` | 821.2px → 482.1px |
| 特大 | `144px 38px 327.7px 240.3px` | `144px 38px 27.5px 540.5px` | 802.7px → 502.5px |

- 「n / n 完了」の右端から説明文の左端までは、標準・大・特大のどれも 8px(列の間隔)になった。
- 0件のとき(「0件」だけを表示): 3列目が 0px で、説明文は「0件」の右端から 16px(間隔2つ分)。標準・大・特大の3つとも同じ並びになった(修正前、大・特大は右端 821px / 803px に寄っていた)。
