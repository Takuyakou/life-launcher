## 4. 行動文の決め方(実装)

| 開始元 | 行動文 |
| --- | --- |
| 今日の3件(`sourceId` が `today:`) | 開始時点のその項目の `text` |
| 今やる一手・プロジェクトの次の一手(`sourceId` がプロジェクト ID) | 開始時点の `nextStep.text` |
| それ以外・空 | `label` |

- 値は開始時に1度だけ決め、`ActiveTimer` に保持する。実行中に元の項目や次の一手を編集しても変わらない。
- 開始メモのテンプレート(`startNoteTemplate`)は `note` にだけ入り、行動文には使わない。
- 実行中タイマーを保存・復元する経路は無い(`ActiveTimer` は画面の状態のみ)。ミニへの通知は `actionText` を含み、含まない古い通知は `label` で表示する。

## 9. 判断メモ

- **ミニの配置**: 実行中のミニは、元から「タイマー」の見出しとプロジェクト名が時計に重なっていた。行動文を足すと高さが足りないため、実行中のときだけ、見出し「タイマー」を出さず、時計(30→26px)と操作ボタン(28→26px)を少し小さくして収めた。ウィンドウサイズ(288×136)とフォーカスの扱いは変えていない。
- **待機中のミニ**: `mini-idle` を変えないため、実行中のときだけ新しい配置を適用している(`timerPanel--active`)。待機中の重なりは P9-03 で直す。
- **サイドバー単独タイマー**: 計画書のテスト項目にあるが、v1.3.4 には、サイドバーから単独で開始する経路が無い(`startTimer` の呼び出しは今やる一手・次の一手・今日の3件のみ)。そのため `label` へのフォールバックは、コードの上で保証している(行動文が空のとき)。
- **今日の3件の行動文**: プロジェクト由来の項目も、計画書どおり開始時点の「項目の文」を使う。
- **ミニでの状態の位置**: 計画書の並び(状態 → 時計)のうち、状態バッジは高さの都合でプロジェクトラベルと同じ行の右側に置いた。
