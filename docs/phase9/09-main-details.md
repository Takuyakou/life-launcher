## 4. 変更内容(指示書の項目との対応)

| 項目 | 内容 |
| --- | --- |
| 1. 待機中のサイドバー Timer | 待機中だけ、分数(34px)の色を `--text-muted-readable`(補足色)にした。大きさは同じ。実行中は `--accent-strong`(黄)、一時停止中は `--warn` のまま。分数入力の上の「通常タイマー」(`.timerHint`)を出さなくした。入力グループの `aria-label="通常タイマーの分数"` は残した。上の「Timer」「通常タイマー」も残した |
| 2. 今日の3件の件数 | 1件以上は `N / M 完了` だけ(`.todaySectionCount` を出さない)、0件は `0件` だけ(`0 / 0 完了` は出さない)。説明文は残した。ほかのセクションの件数は変えていない。見出しの列(`grid-column`)を明示した(下の判断メモ) |
| 3. 「変更」の名前 | カードのボタン「変更」→「編集」。カードの「…」メニューの「次の一手を変更」→「別の行動に入れ替える」。やりたいことで置き換える画面の見出し「次の一手を変更」→「次の一手を入れ替える」(`aria-label` はこの見出しと同じ)。メニューの「次の一手を編集」は変えない。ボタンとメニュー項目に `aria-label` と `title` はもともと無く(`title` は編集できない理由の表示だけ)、名前はそのまま公開される |
| 4. 次の一手カードのメニュー | 「プロジェクトを管理」を外した(次の一手が未設定のカードのメニューも同じメニューなので、同様に外れる)。やりたいことのプロジェクト見出しのメニューには残っている |
| 5. 0件グループの案内 | 開いている0件グループに「見出しを右クリックしてボタンを追加できます」を表示。グループの一部なのでドロップ先は従来どおり(ボタンのドラッグで移せることをテストで確認)。見出しの見た目は変えていない。折りたたんだグループには出さない |
| 6. 満了ダイアログ | 見出しを `actionText`(開始時点の行動文。空なら `label`)にした。Project があるときは、見出しの上に `ProjectIdentity` compact を表示。見出しは長くても3行で止める。ボタンと振る舞いは変えていない |

## 12. 判断メモ

- **今日の3件の見出しの列の指定**: 見出しの表は4列(見出し・件数・完了表示・説明)で、要素を順に置いている。件数を出さなくすると、完了表示が件数の列(30px)に入り、説明と重なった。各要素の列を明示し、完了表示は「件数と同じ位置から始まる」ようにした(ほかの見出しの件数と縦に並ぶ。`phase87-followup-polish` が測っている位置の許容 2px の中)。
- **「別の行動に入れ替える」の画面の見出し**: この画面(やりたいことを選ばずに、空の行動から始める)の見出しは、もともと「次の一手を設定」で、指示書の対象外なので変えていない。指示書で名前を変えたのは「やりたいことで既存を置き換える時」の見出しだけ。
- **案内の文の折り返し**: サイドバーの幅では、案内の文が2行になる(「…追加できま / す」)。文言は指示書どおりで、幅も変えていないので、そのままにした。
- **`.timerHint` のルール**: 使わなくなった `.timerHint` の CSS は残している(提案)。
- **主観的な見た目**: 待機中の分数は補足色になったが、34px・太字のままなので、サイドバーの中では今でも大きい。色の判断は実機で確認してほしい。
