## 4. 共通関数(`src/timerSource.ts`)

| 関数 | 役割 | 使っている場所 |
| --- | --- | --- |
| `sameSourceGeneration(a, b)` | 世代 ID の厳密一致(両方なしは一致、片方だけは不一致) | 下の3つの関数 |
| `timerTodaySourceKey(timer)` | Timer がどの今日の項目のキーに属するか(`today:` の項目自身、または `project:<projectId>`) | `findTodayEntryForTimer`、`timerMatchesProjectNextStep`、`earlyCompletionItem` |
| `findTodayEntryForTimer(entries, timer)` | Timer が対象とする未完了の今日の項目(キー一致 + 世代 ID 厳密一致) | **完了処理**(`finishCompletedTimer`)と、今日の3件の**実行中表示**(`isTimerOnTodayItem`) |
| `timerMatchesProjectNextStep(timer, projectId, generationId)` | Timer が今やる一手のプロジェクトの次の一手を実行中か | 今やる一手の**実行中表示**(`isDoNowRunning`) |
| `timerRunsTodayItem(entries, timer, ownSourceId, sourceKey)` | 今日の項目を Timer が実行中か(自身の Timer、または `findTodayEntryForTimer` が同じ項目を返す) | 今日の3件の実行中表示、**解除の拒否**(ボタン、右クリック、D&D の処理本体、今日やるものを選ぶ画面) |

- 完了処理は、もとの判定(`!item.done`、`sourceKey` 一致、`item.sourceGenerationId === timer.sourceGenerationId`)をそのまま `findTodayEntryForTimer` に移した。条件の順序・厳密さは同じ。
- `earlyCompletionItem` は、キー導出と世代 ID の比較だけを共通関数に置き換えた。一意に1件だけ一致する条件、旧形式の `sourceKey` なしの項目の扱いは変えていない。
- 実行中表示のために別の判定は書いていない。

## 9. 判断メモ

- **実行中判定を共通化した範囲**: 今日の3件の `isRunningTodayItem` に加え、同じ判定を使う「今日の3件から外す」の無効化(カードのボタン、右クリックメニュー)も `isTimerOnTodayItem` に統一した。今やる一手から開始した Timer の対象項目は、実行中は今日の3件から外せなくなる(従来は外せたが、外すと完了が反映されなくなる状態だった)。
- **解除の拒否(処理本体)**: `removeTodayItem`(右クリック、ボタン、D&D の共通の処理本体)の拒否判定は、従来「項目自身の `sourceId` だけ」だった。ボタンとメニューだけを直すと D&D が素通りするため、処理本体も `timerRunsTodayItem` に変えた。
- **今日やるものを選ぶ画面(範囲外の変更、要確認)**: この画面の「今日から外す」(`removeTodayPickerDraftItem`)は、従来、実行中かどうかを一切見ていなかった(直接開始した Timer の項目でも外せた。以前からの穴)。仕様書 §10「UIとhandlerで解除を拒否する」と食い違うため、同じ判定でボタンを無効にし、処理本体も拒否するようにした。仕様書 §9・§10 に追記した。この分は指示書(P9-04)の範囲を少し超えるので、不要なら戻せる(`App.tsx` の2か所)。
- **旧Builder**: `selectedTimerRunning` を使う「今日を組み立てる」の旧markupは `legacyTodayBuilderVisible()` が常に `false` で、画面に出ない。判定だけ共通関数に合わせたが、削除は範囲外。
- **Source Lock の編集可否**: `isTimerActiveForSource`(元の次の一手・やりたいことの編集ロック)は変更していない。
- **ケース3**: Source Lock によって、実行中は UI から次の一手を入れ替えられない(ロックのバッジが出て「変更」ボタンがない)。そのため、入れ替え後の表示は、設定を外部から差し替える形(`updateConfig`)で確かめた。
- **計測中の表示**: 計測では、今やる一手の説明行を「計測中」にして数字を出さない(オーナー指示)。経過時間は操作ボタン左の既存表示だけにした。カウントダウンの「残り mm:ss」は変えていない。基準画像に計測中の画面は無いため、基準画像の更新は `main-running` のみ。
