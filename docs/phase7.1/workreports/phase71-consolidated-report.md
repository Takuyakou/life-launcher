## 2. Phase 7.1本体

### P71-00: 編集同期の監査

Today3、Projectの次の一手、Wishlistの編集経路、データ所有元、保存処理、Timerとの関係を確認し、同期フィールドと安全条件を文書化した。

### P71-01: Today3と登録元の編集同期

- Today3の右クリック「編集」から、元のProject/Wishlistの編集画面を開く。
- 元の登録側から編集した場合も、同じsourceの採用中Today3項目に反映する。
- 文面ではなくProject ID / Wishlist stable IDで対象を特定。同じ文面の別項目を混同しない。
- 常時追従ではなく、明示的な編集保存時にToday3 snapshotを作り直す。
- 保存対象は登録元とToday3を含む1つのconfig。保存失敗時は表示を戻し、編集内容をダイアログに保持して再試行できる。

| フィールド | 編集保存時の動作 |
| --- | --- |
| 行動文 | 登録元の最新文面を反映 |
| きっかけ | Projectの設定を反映。未設定になった値は除去 |
| Project紐付け | 変更・解除を反映 |
| 開始環境のbuttonIds | 選択順を維持して反映。空なら除去 |
| 手順書と開始時に開く設定 | 最新設定を反映。解除も反映 |
| 短時間・通常の分数 | 紐付くProject設定、未設定時は全体設定から解決 |
| sourceKey・完了フラグ・Today3内の位置 | 保持 |
| Session・source完了履歴・Todayの日付・無関係な項目 | 変更しない |

### Timerと早期完了の整合

- 実行中・一時停止中のTimerと同じsourceは編集不可。
- 編集入口だけでなく保存handlerでも判定する。編集中に同じsourceのTimerが開始された場合も保存を拒否する。
- source保存中に同じTimerを開始する経路にもguardを設ける。
- 別sourceのTimerが動いているだけでは、無関係なsourceの編集は禁止しない。
- 停止中に短時間分数を編集すると、次回開始用のToday3 snapshotと早期完了しきい値に反映する。
- Timer実行中のしきい値変更、過去Sessionの変更、次batch仕様の変更は行わない。

### P71-02: 編集画面の配置

- Project/Wishlistのフッターは左「保存」、右「キャンセル」。
- 開始環境Pickerは左「選択を反映」、右「キャンセル」。初期フォーカスはキャンセル。
- Project/Wishlist編集画面の既存テキスト入力への初期フォーカスは維持。
- Project・全体設定のTimer入力を短時間→通常の順へ変更。
- ProjectのTimer入力は900px以下で短時間を上、通常を下に配置。860pxでも検証。

### P71-03: ガイド・仕様・回帰確認

Guideとcurrent-specに編集同期、Timer guard、履歴保持、操作順、早期完了との関係を反映。関連テストを追加し、既存UIとRustの回帰検証を実施した。

## 3. EXE確認後の追加修正

### #37: 一覧レイアウトとホバーの統一

- やりたいことを、次の一手と同じ「左にProject、中央に行動文、右に操作」の横並びへ変更。
- Project未設定の項目は「プロジェクトなし」と表示し、行動文の開始位置を揃える。
- 長い行動文は省略表示し、タイトル属性で全文を確認できるようにした。
- 次の一手・やりたいことの行末「…」から、既存の右クリックメニューを開けるようにした。
- 行のホバー/キーボードフォーカスで背景を強調し、行末操作を表示。タッチ環境では行末操作を常時表示。
- 見出しバーは名称・追加・件数・説明の順に固定。
- 今日を組み立てるの候補行も列位置・行高・ホバー表示を統一。右端の「今日へ」「選択済み」は維持。
- 「選択済み」の折り返しを防ぐため、ボタン内の横余白と改行規則を調整。
- 採用、候補除外、D&D、保存、Timerの処理は変更していない。

### #38: 密度と見出しの微調整（最終仕様）

- 今日を組み立てる・次の一手・やりたいことの最小行高を52pxから48pxへ変更。
- 上下paddingを7pxから5pxへ縮小。行動文や操作ボタンの文字サイズは維持。
- 候補内の「次の一手」「やりたいこと」見出しは、「今日の3件」と同じmuted色・太さ650に変更。
- 見出しサイズは「今日の3件」の14pxより1px小さい13px。
- やりたいことの左端の装飾線は最終的に削除。共通の列位置を保つ透明な余白は維持。

左線は参考HTMLに従い追加後、いったん維持の指定を経て、最終指示により非表示とした。現行仕様は「左線なし」。

## 7. 残る注意点・対象外

- 旧形式の文面依存Wishlist採用キーは移行しない。安全に編集できない採用項目はToday3から外して再採用する案内を出す。
- config保存の整合はアプリ単位。既存ファイル保存fallbackのクラッシュ耐性、複数window間の古いconfigによる上書き競合は今回解決していない。
- 開始環境snapshotはbutton IDsを保持し、外部アクション内容そのものを独立複製しない。
- 生成された既存スクリーンショット差分と無関係な報告書は、今回のPRへ含めず保持した。
- 正式リリース前には、確定したrelease sourceからの再ビルド、移行・native smoke・配布物の検証が別途必要。
- README、正式CHANGELOG/Release notes、Web Demo同期、署名導入は今回の対象外。
