## 1. プロダクト概要

### 1.1 目的

Life Launcherは、迷っているユーザーに「今やる一手」を渡し、必要なアプリ・ファイル・URL・手順書とタイマーを一続きで起動するWindows向け実行支援アプリである。

予定を細かく管理することより、次の流れを短くすることを重視する。

1. 今日の方向を決める。
2. 実行可能な一手を選ぶ。
3. 必要な作業環境を開く。
4. 短時間または通常時間のタイマーを開始する。
5. 実行結果をローカルへ記録する。

### 1.2 中心となる価値

- サイドバーの少数精鋭ランチャーから、よく使う対象をすぐ開ける。
- 辞書ウィンドウから、多数の登録対象を検索して呼び出せる。
- 「今日の勝利条件」「今日の3件」「今やる一手」で判断負荷を下げる。
- プロジェクトの次の一手と作業環境を結び付けられる。
- タイマー記録から、その日の実行内容を自動生成する。
- ローカルのMarkdown、Text、HTML手順書を作業中に参照できる。
- アカウントや自前サーバーを必要とせず、データを端末内に保持する。

### 1.3 設計原則

- 実行開始までの操作数を少なくする。
- 自動確定より、ユーザーが最後に確定する余地を残す。
- 推薦は説明可能な固定ルールだけを使う。
- メイン画面は中程度の情報密度を保つ。
- 補助情報は折りたたみ、辞書、設定、別ウィンドウへ分離する。
- 黄色を意思決定とフォーカスに使い、状態色を意味別に使い分ける。
- Windowsアプリとして、マウス、キーボード、D&D、トレイを一貫して扱う。

## 2. 対応環境とウィンドウ

- 対象OSはWindows。
- メインウィンドウは初期 `1080 x 680`、最小 `860 x 560`、リサイズ可能。
- 多重起動時は新しいプロセスを増やさず、既存のメインウィンドウを復元する。

| ウィンドウ | 用途 | 主な特徴 |
| --- | --- | --- |
| Main | 今日の実行、記録、設定、使い方 | 閉じる操作ではトレイへ格納 |
| Dictionary | ランチャー辞書 | フレームレス。検索、分類、D&D |
| Instruction Viewer | 手順書の閲覧・管理 | Markdown、Text、HTMLを表示 |
| Mini | タイマーの小型表示 | `288 x 136`、常に手前、タスクバー非表示 |

### 2.1 トレイ

- メインの閉じるボタンでは終了せず、通知領域へ格納する。
- 実行中・一時停止中のタイマーは維持する。
- トレイアイコンの左クリックでメインを復元する。
- トレイメニューから「開く」と明示的な「終了」を選べる。

## 3. メイン画面構造

```text
Main Window
├─ Sidebar
│  ├─ Brand
│  ├─ Dictionary launcher
│  ├─ Quick launcher groups
│  └─ Timer panel
└─ Main panel
   ├─ Page header / top toolbar
   ├─ Victory condition
   ├─ Do now
   ├─ Today builder
   ├─ Today 3
   ├─ Project next steps
   ├─ Wishlist
   └─ Today activity
```

- サイドバー幅は `244px`。
- メイン内容幅は最大 `1180px`。
- 最大化時はメイン領域内で中央寄せし、片側だけに余白を偏らせない。
- サイドバーとメイン領域は独立してスクロールする。
- 上部ヘッダーは本文スクロールから分離する。

- 黄色は選択、挿入位置、フォーカス、勝利条件。
- 緑は短時間開始、実行中、成功。
- 青は通常タイマー開始。
- 橙は一時停止、赤は終了・削除・破棄。
- プロジェクト色はamber、blue、green、violet、rose、cyan、orange、slate。

### 4.2 文字と形状

- 基本フォントは `Segoe UI`, `Yu Gothic UI`, `Meiryo`, `system-ui`, `sans-serif`。
- ページタイトル約22px、勝利条件・今やる一手約17px、見出し・本文約14px、補足約11px。
- 文字間隔は0を基準とし、負のletter-spacingは使わない。
- 基本角丸は `8px`。
- セクション全体を装飾カード化せず、カードは個別項目と操作面に限定する。
- 長いラベルは省略表示とツールチップで補完する。
- ボタン、カード、ツールバーには安定した寸法を与える。

## 5. 左サイドバー

### 5.1 ブランドと辞書

- 左上にカラーアイコン、`Life Launcher`、`Quick`を表示する。
- 上部に「辞書を開く」と `Ctrl+K` を表示する。
- クリックまたは設定済みショートカットで辞書を開く。

### 5.2 Quickグループとボタン

- `showInSidebar=true` のランチャーだけを表示する。
- グループは折りたたみでき、状態をローカルに保持する。
- 見出しには名称と項目数を表示する。
- グループの右クリックから追加、名称変更、削除を行う。
- グループはD&Dで並べ替えられる。
- ボタンはアイコンとラベルを表示し、クリックでアクションを定義順に実行する。
- ボタンの右クリックから編集、削除を行う。
- ボタンは同一グループ内および別グループへD&D移動できる。
- 約6pxの開始しきい値で通常クリックとの誤判定を避ける。
- ドラッグ対象にはゴースト、移動先には黄色の挿入線を表示する。
- ドラッグ中以外は挿入線を表示しない。
- 初期configは特定用途のサンプルを持たない汎用的な空状態。

### 5.3 サイドバータイマー

- 待機中は通常タイマーの分数を表示する。
- `-` / `+` は5分単位、数値入力とスピナーは直接変更。
- 分数表示の上下ドラッグは1分単位。
- 設定範囲は1〜240分。
- 実行中は対象名、残り時間、進捗、一時停止、終了を表示する。
- 一時停止中は再開と終了を表示する。

## 6. 上部ヘッダー

- メイン画面のタイトルは `今日 ・ N分`、隣に月日と曜日を表示する。
- 記録画面では「記録」に切り替える。
- 意味が曖昧だった「通常」バッジは表示しない。

| グループ | 日本語 | 英語 | 役割 |
| --- | --- | --- | --- |
| System | 自動起動 | Startup | Windows自動起動 |
| System | ミニ | Mini | ミニタイマー |
| View | 記録 / メイン | Records / Home | 画面切替 |
| View | 手順書 | Instructions | 手順書ビューアー |
| Help | 使い方 | Guide | アプリ内ガイド |
| Help | 設定 | Settings | 設定ダイアログ |

- アイコンと短い名称を併記する。
- 日本語または英語は実行環境の言語に合わせる。
- ホバー時は背景、境界、文字色を変える。
- 自動起動が有効な場合は緑の状態表現を維持する。
- 狭い幅ではラベルを段階的に隠し、アイコン、ツールチップ、ARIAラベルは残す。

## 7. 今日の勝利条件

- 今日もっとも達成したい状態を1件だけ表示する。
- 金色の枠とトロフィーで優先度を示す。
- チェックボックスで達成状態を切り替える。
- 本文はインライン編集でき、最大90文字。
- 候補チップは入力欄へのセットまでとし、自動確定しない。
- 勝利条件の自動生成、AI提案、達成率表示は行わない。

## 8. 今やる一手

- 説明可能な固定ルールで1件を提示する。
- 今週の重点、当日のセッション有無、更新・確認時刻、手動順序を材料にする。
- 推薦理由を短い補足として表示する。
- AI、利用回数順、非公開スコアを使わない。
- プロジェクト色、名称、次の一手、任意の開始トリガー、通常時間を表示する。
- 14日以上実行がない場合は短時間からの再開を案内する。
- 関連手順書がある場合だけ手順書ボタンを表示する。
- 右側上部に短時間開始と通常開始を横並びで表示する。
- 短時間は緑、通常は青。分数はグローバルまたはプロジェクト設定に連動する。
- 開始時は関連ランチャー、手順書、タイマーを同じ実行経路で扱う。
- 実行アクションがなくても、手順書の開始時表示があればタイマーを開始できる。
- 実行中は一時停止と終了、一時停止中は再開と終了へ切り替える。

## 9. 今日を組み立てる

- 候補からその日の行動を選ぶ折りたたみセクション。
- 「今やる一手」と「今日の3件」の間に配置する。
- プロジェクトの次の一手、やりたいこと、勝利条件、最近の記録等から候補を構成する。
- 内部名のInboxではなく「やりたいこと」と表示する。
- 候補を「今日の3件」「今日の勝利条件」「やりたいこと」へ追加できる。
- 今日の3件が3件の場合は制限を超えて追加しない。
- 見出し内の小さな追加ボタンと、展開時の追加行を持つ。
- 候補はD&Dと右クリックの上下移動で並べ替えられる。
- 約6pxのしきい値、ゴースト、黄色の挿入線で状態を示す。
- 表示順はローカルUI状態として保持する。

## 10. 今日の3件

- 当日に取り組む項目は最大3件。
- 見出しの隣に `+ 追加`、`N/3` の順で表示する。
- 3件制限を解除する設定や回避経路は持たない。
- 未完了項目を翌日へ自動繰り越ししない。
- チェックボックスと項目名を表示する。
- プロジェクトがある場合、色付きドットと名称を本文の基準線に揃える。
- 任意の「きっかけ」を持てる。
- きっかけ追加はホバー・フォーカス中だけ現れ、チェック後に不要な状態を残さない。
- 最終行に重複した罫線を表示しない。
- 右クリックから削除できる。
- 短時間開始と通常開始を常時表示する。
- ボタン幅は2桁以上の分数でも崩れない固定寸法。
- 初期状態は再生アイコン、ホバー時は分数を表示する。
- 短時間は緑、通常は青。
- 実行中は一時停止と終了、一時停止中は再開と終了へ切り替える。
- プロジェクト、ランチャー、手順書が紐づく場合は開始時に同じ実行環境を利用する。

## 11. プロジェクトの次の一手

- 自動折り返しグリッドで表示し、カードの最小幅は約245px。
- プロジェクト色、名称、次の一手、任意の開始トリガーを表示する。
- 初期状態の開始ボタンは再生アイコン、ホバー時は分数を表示する。
- 左に緑の短時間開始、右に青の通常開始を置く。
- 手順書がある場合だけ手順書操作を表示する。
- 見出しの隣に追加ボタンと件数を表示する。
- カードはD&Dで並べ替えでき、ゴーストと挿入位置を区別する。
- 右クリックから上へ移動、下へ移動、編集、削除を行える。
- 編集ではサイドバーに加え、初期状態が閉じた辞書内の登録対象も選べる。
- プロジェクトごとに通常時間、短時間、開始メモ、手順書、開始時の手順書表示を持てる。

## 12. やりたいこと

- 後で整理する内容の一時置き場で、初期状態は折りたたむ。
- 見出し補足は「あとで整理する一時置き場」。
- 小さな追加ボタンと件数は見出し枠内に置く。
- 展開時は一覧先頭に全幅の追加行を表示する。
- 項目名は今日の3件より少し抑えた濃度で可読性を保つ。
- D&Dで並べ替え、ゴーストと黄色挿入線を表示する。
- 右クリックから上へ移動、下へ移動、編集、削除を行う。
- 編集は専用ダイアログで行う。
- 本文、プロジェクト、実行ボタン、手順書、開始時の手順書表示を設定できる。
- プロジェクト設定時は、次の一手と同じ濃度・サイズで色と名称を表示する。
- 「今日へ」で今日の3件へ移せるが、3件上限を超えない。

## 13. 今日の実行

- 当日のセッションから自動生成する。
- 手入力の「今日できたこと」入力欄は持たない。
- 初期状態は折りたたむ。
- 見出し補足は「タイマーで実行した内容」。
- 緑の「自動」表示と件数を重ならないように表示する。
- 行には開始時刻、プロジェクト色、名称、実行名、分数を表示する。
- セッションnoteを分類・タグ化しない。
- セッション追加、編集、削除、復元、ホットリロード後に再計算する。
- 件数上限は設けない。

## 14. タイマー

```text
待機中
  └─ 開始 → 実行中
              ├─ 一時停止 → 一時停止中
              │                ├─ 再開 → 実行中
              │                └─ 終了 → セッション確定
              ├─ 終了 → セッション確定
              └─ 満了 → 完了通知 + セッション確定
```

- アクティブなタイマーは常に1本だけ。
- 実行中または一時停止中に別タイマーを開始すると、古いタイマーを終了扱いで確定する。
- 古い項目の実行中・一時停止表示を解除してから新しいタイマーを開始する。
- 一時停止時間は実行分数へ含めない。
- 手動終了、切り替え、満了時にセッションを確定する。
- 1分未満の実行は通常のセッション記録へ追加しない。
- 満了後は15分の延長導線を持つ。
- noteは自由テキストのまま保存する。
- 開始・一時停止時は右下にトーストを表示する。
- 複数トーストは重ならず積み、右から入り右へ消える。
- 満了時はメインを復元し、OS通知と完了ダイアログを表示する。

### 14.1 ミニウィンドウ

- 固定サイズ `288 x 136`、フレームレス、常に手前、タスクバー非表示。
- 自動表示時にフォーカスを奪わない。
- タイトル領域をドラッグして移動できる。
- ダブルクリックまたは拡大操作でメインへ戻る。
- 最後の位置を保存し、モニター外へ出た場合は補正する。

## 15. 辞書ウィンドウ

### 15.1 基本とロック

- `showInOverlay=true` の登録だけを表示するコマンドパレット。
- 初期 `760 x 520`、最小 `420 x 300`、フレームレス、リサイズ可能。
- 位置とサイズを保存し、画面外を補正する。
- 辞書表示中はメイン画面を暗くする。
- 閉じるボタンの左にロック切替を置き、初期状態はロック中。
- ロック中は範囲外クリックや他ウィンドウ操作で閉じず、暗転も維持する。
- ロック解除中は範囲外クリックで閉じる。
- ロック解除中でもタイトルバーのドラッグで移動できる。

### 15.2 ページ、検索、タイル

- 固定ページ「すべて」「未分類」とユーザー作成ページを表示する。
- 選択中ページだけを選択状態にする。
- 固定ページは並べ替え対象外、ユーザーページはD&Dで左右へ移動できる。
- ラベル、グループ、ページ名、aliases、説明を検索対象にする。
- 最近使ったもの、おすすめ、使用回数順は持たない。
- 登録数にかかわらずタイル寸法を共通化する。
- 長いラベルは省略し、titleで全文を補完する。
- タイルは同一ページ内と別ページ間でD&D移動できる。
- ゴーストはポインターから約10pxずらす。
- 別ページタブへ一定時間ホバーするとページを切り替える。

### 15.3 右クリック

- 移動、サイドバーへ追加、編集、削除を行う。
- 「サイドバーへ追加」は対象項目単位で有効状態を判定する。
- サイドバーへ追加しても辞書から削除しない。
- 完了メッセージは約3秒で消える。
- メニューは最終位置へ即時配置し、横から滑り込まない。
- 画面端では内側へ補正する。
- `role=menu`、キーボード操作、Escape終了に対応する。

## 16. ランチャー登録と編集

### 16.1 対応アクション

1つのボタンは複数アクションを持ち、登録順に実行できる。

- アプリ、URL、フォルダー、ファイルを開く。
- スクリプトを引数付きで実行する。
- Windowsのごみ箱を開く。

URLはWindowsの既定ブラウザで開き、登録ごとのブラウザ指定は持たない。

### 16.2 外部D&D

- アプリ、フォルダー、ファイル、Windowsショートカット、URL、ごみ箱を受け付ける。
- ブラウザのタブ、アドレス、ブックマークURLも受け付ける。
- `.lnk` はリンク先を解決する。
- Chromeブックマークは、利用可能な場合にアクティブプロファイルから名称を得る。
- 複数項目は先頭を登録候補にする。
- ドロップだけで起動せず、確認ダイアログを経て保存する。
- 確認画面ではラベル、グループ、サイドバー、辞書、辞書ページを選ぶ。

### 16.3 アイコン

- ローカル対象はWindows Shell由来のアイコンを非同期取得する。
- ショートカット矢印を合成せず、リンク先アイコンを優先する。
- URLは対象ページまたは `/favicon.ico` から非同期取得する。
- 第三者favicon APIは使わない。
- 失敗時はUIを停止せず、種別フォールバックを使う。
- メンテナンスからキャッシュを再生成できる。

## 17. 手順書ビューアー

### 17.1 ウィンドウと左ペイン

- 初期 `960 x 680`、最小 `720 x 480`、リサイズ可能。
- 状態を保存し、モニター外を補正する。
- 常に手前は既定で有効。
- 自動表示時はフォーカスを奪わない。
- 閉じる操作は手順書ウィンドウだけを破棄する。
- 左ペインは約248px。
- 検索欄は「検索」、ほかに「読み込み」と更新を置く。
- 上部の常設「新規」ボタンは表示しない。
- 読み込みルートは最大5件で、再起動後も保持する。
- フォルダー名変更時は保存した識別情報から可能な範囲で追跡する。
- フォルダー選択ダイアログは完了まで前面に保持する。

### 17.2 対応形式

| 形式 | 表示 | 編集 | アイコン色 |
| --- | --- | --- | --- |
| Markdown | サニタイズ済みHTML | プレーンテキスト | 黄系Book |
| Text | 改行保持テキスト | プレーンテキスト | 青系FileText |
| HTML | サンドボックスiframe | 読み取り専用 | 橙系FileCode |
| Folder | ツリー階層 | 管理操作 | フォルダー色 |

- HTMLはインラインCSSを保持したサニタイズ済み `srcDoc` を使う。
- iframeは `sandbox="allow-same-origin"`。
- script、form、入れ子iframe、object、外部リソース等を除去する。
- HTTP/HTTPSリンクは外部ブラウザで開く。

### 17.3 ツリーと編集安全性

- 任意の深さの階層を表示する。
- 同一親内でD&D表示順を変更し、ローカルに保持する。
- ファイルとフォルダーの右クリックメニューを持つ。
- ファイルの「エクスプローラーで表示」は含有フォルダーを開く。
- 削除はWindowsのごみ箱を使い、永久削除へフォールバックしない。
- キーボード操作とARIA tree semanticsに対応する。
- MarkdownとTextは明示的に編集開始し、保存または破棄する。
- 保存は一時ファイルと置換によるアトミック経路。
- mtime競合を検出し、外部変更を約2.5秒間隔で確認する。
- 登録ルート外、UNC、パストラバーサル、危険なリンク構造を拒否する。
- プロジェクト、次の一手、やりたいことへ手順書を紐づけられる。

## 18. 記録ビュー

- 今日と今週の合計時間。
- 今週のプロジェクト別時間。
- 全期間のプロジェクト別活動日数と合計分数。
- 直近セッション一覧。
- 前週の合計、活動日数、プロジェクト別時間、セッション数。
- 週次レビューは固定された事実だけを表示する。
- ランキング、前週比評価、達成率、ストリーク、グラフは表示しない。
- 今日、今週、全期間、プロジェクト、テキストで絞り込める。
- セッションを手動追加、編集、削除できる。
- noteは自由テキストのまま扱い、タグ抽出、分類、集計を行わない。
- 旧形式noteは互換表示する。
- 今日の活動ログをクリップボードへ出力できる。
- 出力には合計、プロジェクト別・項目別分数、時刻、作業名、noteを含める。
- 外部サービスへ自動送信しない。

## 19. 設定

タブは「基本」「ショートカット」「手順書」「バックアップ」「メンテナンス」。

| 基本設定 | 既定値 | UI |
| --- | --- | --- |
| 通常タイマー | 25分 | 入力、スピナー、上下ドラッグ |
| 短時間タイマー | 5分 | 入力、スピナー、上下ドラッグ |
| 1日の開始 | 4時 | 入力、スピナー、上下ドラッグ |
| 常に手前 | OFF | チェック |
| Windows自動起動 | OFF | チェック |
| ミニモード | ON | チェック |
| 今週の重点 | 未設定 | 最大3件 |

| ショートカット | 既定値 |
| --- | --- |
| メイン画面 | `Alt+Space` |
| 辞書 | `Ctrl+K` |
| ミニ | 未設定 |
| 手順書 | 未設定 |

- ショートカットは登録ボタンを押した後のキー入力を記録する。
- 記録中は既存ショートカットを一時解除する。
- 重複や使用中キーを検証し、警告する。
- 登録失敗で設定全体の読み込みを失敗させない。
- 保存完了まで本登録しない。
- 未保存で閉じる場合は確認ダイアログを出す。
- 「編集を続ける」と「破棄して閉じる」は同じ文字サイズと高さにする。

### 19.1 バックアップとメンテナンス

- バックアップ先と保持数を設定でき、既定保持数は30。
- 設定済みの場合、1日1回 `config.json`、`sessions.jsonl`、`notes.json` をZIP保存する。
- ZIPを選択して復元し、復元前に現在データを退避する。
- ZIPの名前、エントリー、サイズ、圧縮形式、チェックサムを検証する。
- データフォルダー、バックアップを開ける。
- アイコン再生成、今日の活動ログコピーを実行できる。

## 20. フィードバックとアクセシビリティ

- トーストは右下へ表示し、最大幅は約420px。
- 複数トーストは重ならず積む。
- 成功、情報、警告、エラーを色とアイコンで区別する。
- ダイアログは安全側へ初期フォーカスを置き、Tabを内部へ閉じ込める。
- 標準 `alert`、`confirm`、`prompt` や `tauri.localhost` を製品UIへ露出させない。
- コンテキストメニューは即時配置し、画面外を補正し、横から滑り込まない。
- 主要アイコンボタンにはARIAラベルとツールチップを付ける。
- フォーカスリングは2pxのアクセント色。
- クリック可能領域はポインターカーソル。
- 辞書、メニュー、手順書ツリーをキーボードで操作できる。
- スキップリンクを持つ。
- `prefers-reduced-motion` を尊重する。
- 色だけに依存せず、文字、アイコン、境界を併用する。

## 21. データと日付

| ファイル / フォルダー | 用途 |
| --- | --- |
| `config.json` | ランチャー、プロジェクト、今日、やりたいこと、設定 |
| `config.schema.json` | configのJSON Schema |
| `sessions.jsonl` | タイマーと手動追加のセッション |
| `notes.json` | 旧形式互換データ |
| `icons/` | アイコンキャッシュ |
| `backups/` | 更新前退避 |

- configの現行データ版は `2`。
- UIからのconfig書き込みはRustのアトミック保存経路へ統一する。
- 外部変更はホットリロードする。
- 既定の1日開始時刻は4時。
- `date_key_at` と `today_date` を共通の日付判定に使う。
- 開始時刻より前は前日扱い。
- 今日、セッション、記録、日次バックアップで同じ境界を共有する。
- 日付変更時は今日の項目を初期化し、未完了を自動繰り越ししない。

## 22. ネットワークと権限

### 22.1 favicon取得

- HTTP/HTTPSだけを許可し、資格情報入りURLを拒否する。
- localhost、loopback、link-local、private、特殊用途IPv4/IPv6を拒否する。
- DNS解決結果を検査し、検査した宛先へ接続を固定する。
- プロキシを介さず、リダイレクトは最大5回。
- 接続3秒、1リクエスト6秒、全体15秒のタイムアウト。
- HTML最大512KiB、画像最大2MiB、候補最大8件。
- Content-Typeを検査し、画像はデコード後に保存する。

### 22.2 Tauri capability

| ウィンドウ | 主な許可 |
| --- | --- |
| Main | 基本API、補助Webview、表示、フォーカス、位置・サイズ、常時手前、自動起動、状態保存 |
| Dictionary | 基本API、非表示、フォーカス、ドラッグ、リサイズ、状態保存 |
| Instruction | 基本API、破棄、常時手前切替 |
| Mini | 基本API、ウィンドウドラッグ |

- 補助ウィンドウへMain専用権限を付与しない。
- capability契約をRustテストで確認する。

## 23. レスポンシブ動作

- 最小幅内でサイドバーと主要操作を維持する。
- 上部ラベルを段階的に省略しても、アイコンと操作は残す。
- プロジェクトカードは自動折り返しする。
- 長い日本語・英語は省略または改行し、隣接操作へ重ならない。
- 辞書と手順書は個別の最小サイズと内部スクロールを持つ。
- ビューポート幅で文字サイズを連続拡大縮小しない。

## 24. 明示的な非目標

- カレンダー、ヒートマップ、ストリーク、達成率、ランキング、統計グラフ。
- 未完了タスクの自動繰り越し、今日の3件制限解除。
- 期限、優先度、サブタスク、一般的なタグ管理。
- アカウント、ログイン、自前サーバー、クラウド同期、スマートフォン連携。
- AI提案、自動分類、自動確定。
- 勝利条件や次の一手の自動セット。
- 辞書の最近使ったもの、おすすめ、使用回数順。
- noteのタグ抽出、分類、集計。
- URLごとのブラウザ指定。
- 活動ログの自動送信、週次重点の自動リセット。

## 25. 主要な不変条件

1. アクティブまたは一時停止中のタイマーは1本だけ。
2. 今日の3件は最大3件。
3. サジェストは入力欄へのセットまでで、確定はユーザー操作。
4. configのUI書き込みは既存のアトミック保存経路を使う。
5. 日付判定はRustの共通関数へ集約する。
6. ミニウィンドウの自動表示はフォーカスを奪わない。
7. ドロップ対象を確認なしで起動しない。
8. 手順書削除はごみ箱を使い、永久削除へ自動移行しない。
9. セッションnoteは自由テキストのまま保持する。
10. 推薦は説明可能な固定ルールだけを使う。

## 26. 現行制限

- UIは日本語中心で、英語対応は主に上部ツールバー等の一部表示。
- URLはWindowsの既定ブラウザで開く。
- favicon取得失敗時はフォールバックアイコンになる。
- Chromeブックマーク名取得はローカルプロファイルを読める場合に限る。
- HTML手順書は安全性のためスクリプトや外部リソースを除去し、通常ブラウザと完全同一ではない。
- 手順書フォルダー追跡はローカルドライブ上の安全なパスを前提とする。
- `notes.json` は互換目的で残るが、「今日の実行」は `sessions.jsonl` から生成する。
- アプリ内自動アップデーターは現行仕様に含まれない。
