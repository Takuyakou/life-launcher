# Life Launcher v1.3.0

「今日やるものを選ぶ」流れと、プロジェクト・次の一手・やりたいことの関係を整理し、バックアップとソフトウェアリセットを実用段階まで強化する更新です。

## 主な変更

### 今日やるものを選びやすく

- 今日の3件に空きがあるときは「＋ 今日やるものを選ぶ」から選択画面を開き、次の一手・やりたいことを「＋ 今日へ」で選べます。
- 選択済み項目は選択画面上部へ固定表示し、「今日から外す」で解除できます。「決定」で確定し、「キャンセル」は変更前へ戻します。
- 3件目の保存に成功すると、決定操作と同じ扱いで選択画面を自動的に閉じます。
- メイン画面の次の一手カード・やりたいこと項目から、今日の3件へドラッグして追加できます。
- 「今日の3件」のカードは並べ替えに加え、ドラッグ中だけ表示される専用領域から今日への採用だけを外せます。直後の通知から元に戻せます。

### プロジェクト・次の一手・やりたいことを整理

- プロジェクトの概要と次の一手の実行設定を分離し、各プロジェクトへ0〜1件の次の一手を設定する構造へ更新しました。
- 次の一手は既存のやりたいことから選ぶか、新しく入力できます。置換時は古い一手をやりたいことへ戻すか、完了扱いにするかを選べます。
- やりたいことはプロジェクト別に整理し、未所属項目は「未分類」へまとめます。現在の次の一手・今日の3件への設定状態を一覧で確認できます。
- 未完了の今日の3件が参照している登録元は鍵付きになり、完了または採用解除まで不用意な編集・削除・置換を防ぎます。
- プロジェクトを削除するときは関連する次の一手・やりたいことの件数を確認し、削除または完了扱いを選べます。過去の実行記録は残ります。

### 今やる一手とタイマー

- 次の一手がある全プロジェクトから、今週の重点、鮮度、表示順を使う固定ルールで「今やる一手」を選びます。
- 候補が複数ある場合は「他の一手」で表示だけを切り替え、優先順や保存データは変更しません。
- 短時間・通常タイマーに加え、0:00から時間を決めずに進める「計測」を追加しました。
- 今日の勝利条件は、チェックするたびに短い達成演出を再生します。表示は演出中も演出後も「✓ 今日の勝利、達成」のまま切り替わりません。

### 設定・バックアップ・リセット

- 設定画面を「基本」「ショートカット」「手順書」「バックアップ」「メンテナンス」へ整理しました。
- 日次ZIPバックアップへ設定、実行記録、互換メモ、schemaに加えてアイコンキャッシュを保存します。
- ZIP復元前に現在データとアイコンを退避します。旧形式のZIPにアイコンがない場合は、現在のアイコンキャッシュを保持します。
- ソフトウェアリセットは、バックアップ選択と最終確認を分け、内部の復元用記録と処理記録を使い、失敗時や次回起動時に復旧を行います。
- リセット・復元後の自動起動更新、グローバルショートカットの二重登録、連続復元時のファイル競合を修正しました。
- 登録元のファイルやショートカットが後から削除されても、取得済みアイコンはキャッシュから表示を維持します。

### UIとGuide

- 今日の3件、今やる一手、次の一手、やりたいことのプロジェクト色、ホバー、操作位置、空状態、狭い画面での配置を統一しました。
- アプリ内Guideを現在の選択画面、登録元の保護、プロジェクト削除、計測、バックアップ、リセット操作へ同期しました。
- 確認画面と選択画面は範囲外クリックで閉じず、未保存の変更がある場合だけ破棄確認を表示します。

## v1.2から更新する方へ

- config schemaは`2`から`3`へ更新されます。初回読み込み時に変換前のraw backupを作成し、変換・検証・backupのいずれかが失敗した場合は元のconfigを書き換えません。
- プロジェクトに残っていた次の一手の開始環境・手順書・タイマー設定は、v3で次の一手自身へ移行します。本文がない旧設定は保留し、最初の次の一手設定時に引き継ぐか破棄するかを選べます。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`を別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式           | ファイル名                                      | 用途                     |
| -------------- | ----------------------------------------------- | ------------------------ |
| Installer      | `Life-Launcher-v1.3.0-windows-x64-setup.exe`    | 通常のインストール用     |
| Standalone EXE | `Life-Launcher-v1.3.0-windows-x64.exe`          | インストールせず直接起動 |
| Portable ZIP   | `Life-Launcher-v1.3.0-windows-x64-portable.zip` | 展開して起動             |
| SHA256         | `SHA256SUMS.txt`                                | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
