# Life Launcher v1.2.0

「少し進めた」をその場で確定し、今日の候補を選び直しやすくする更新です。

## 主な変更

### 途中で止めても、今日の完了を選べる

- 短時間タイマーの基準を満たし、通常の予定時間より前に手動停止した「今日の3件」の項目では、早期完了の確認を表示します。
- 左の「今日の分は完了」は実行記録を保存して対象の「今日の3件」の項目だけを完了にします。右の「未完了のまま終了」は実行記録を保存し、対象の項目を未完了のまま残します。
- Escapeと閉じる操作は「未完了のまま終了」と同じです。確認待ちや保存待ちの時間は実行記録へ加算しません。
- 元の次の一手、やりたいこと、プロジェクト、候補、完了履歴は変更しません。3件すべて完了した場合だけ、従来どおり手動で次の3件を選びます。

### 今日の3件と登録元の編集を同期

- 今日の3件、今日を組み立てる、次の一手、やりたいことの右クリックまたは「…」から、同じ登録元の編集画面を開けます。
- 行動文、きっかけ、プロジェクト、開始環境、手順書、短時間・通常タイマーを明示的な保存時に今日の3件へ反映します。
- 同じ文面ではなくプロジェクトの識別情報とやりたいことの識別情報で対象を特定し、同名の別項目を混同しません。
- 対象登録元のタイマーが実行中・一時停止中の場合は編集できません。編集中に同じタイマーが始まった場合も保存を拒否します。

### 今日の選択を戻しやすく

- 「今日の3件から外す」と「今日の候補から外す」に「元に戻す」を追加しました。
- 「元に戻す」は対象項目だけを戻し、その後に行った並べ替え、設定変更、実行記録、完了履歴を上書きしません。
- 次の一手・やりたいことの明示除外済み項目は、メニューまたはドラッグ操作で「今日を組み立てる」へ戻せます。今日の3件へ自動採用はしません。

### ドラッグ操作と一覧表示を改善

- 「今日を組み立てる」の候補を今日の3件へ、明示除外した登録元を「今日を組み立てる」へドラッグして移動できます。
- ドラッグ操作開始直後から有効な移動先を黄色の枠・背景・案内で表示し、ドロップ位置では挿入線を表示します。
- 案内はoverlay表示のため、ドラッグ開始時に画面全体や下の項目が押し下げられません。
- ドラッグ中の移動では保存せず、成功したドロップ時だけ1回保存します。保存に失敗した場合は元の順序と表示へ戻します。
- 次の一手・やりたいことは件数に応じて全表示、5件＋展開、10件単位のページ表示へ切り替わります。

### フィードバックとタイマー操作

- 保存に成功した勝利条件、今日の3件、正確な3/3完了、今やる一手へ短い完了フィードバックを追加しました。
- 右下の通知表示を統一しました。通常は4秒、「元に戻す」付きは8秒で、ホバー・フォーカス・画面非表示中は残り時間を停止します。
- サイドバーの待機中タイマー分数を上下へのドラッグで変更できます。実行中・一時停止中は変更できません。
- 今日の3件の開始ボタン幅、一覧の行高、ホバー、メニュー表示、見出しを揃えました。

## v1.1から更新する方へ

- config schemaはv1.1と同じ`2`です。v1.1からの追加のデータ変換はなく、登録、今日の3件、実行記録、完了履歴をそのまま使用します。
- 更新前にLife Launcherを完全終了してください。必要に応じて`%APPDATA%\life-launcher`フォルダーを別の場所へコピーしてください。
- 自動アップデーターはありません。このリリースの配布物を使用して更新してください。

## 配布ファイル

| 形式 | ファイル名 | 用途 |
| --- | --- | --- |
| Installer | `Life-Launcher-v1.2.0-windows-x64-setup.exe` | 通常のインストール用 |
| Standalone EXE | `Life-Launcher-v1.2.0-windows-x64.exe` | インストールせず直接起動 |
| Portable ZIP | `Life-Launcher-v1.2.0-windows-x64-portable.zip` | 展開して起動 |
| SHA256 | `SHA256SUMS.txt` | 配布ファイルの整合性確認 |

ZIP版もユーザーデータの保存先は`%APPDATA%\life-launcher`です。USB等へデータごと持ち運ぶ方式ではありません。

## 動作要件・注意事項

- Windows 10以降（x64）とMicrosoft Edge WebView2 Runtimeが必要です。
- 配布バイナリはコード署名されていません。Windows SmartScreenの警告が表示されることがあります。
- アカウント、テレメトリ、クラウド同期、自動アップデーターはありません。
- 通信、Tauri capability、permission、dependency、config schemaはv1.1から変更していません。

Web Demoは別リポジトリ・別公開工程です。この本体更新はWeb Demoへの同時反映を意味しません。
